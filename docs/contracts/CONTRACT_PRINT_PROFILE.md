# Profile چاپ قرارداد

تنظیمات چاپ در کلیدهای `contract_print_*` ذخیره می‌شوند و با `ContractPrintProfile` validate می‌شوند. profile شامل حاشیه‌ها، فونت، line-height، فاصله پاراگراف و عنوان، هدر، لوگو، جدول، امضا، footer و حالت رنگ است.

محدوده‌ها مانع CSS منفی، expression و مقدارهای خارج از بازه می‌شوند. CSS چاپ فقط متغیرهای عددی اعتبارسنجی‌شده را دریافت می‌کند.
