# نسخه‌بندی قالب قرارداد

وضعیت‌ها: `draft`، `published`، `superseded` و `archived`.

- ذخیره فقط نسخه draft تازه می‌سازد.
- انتشار، نسخه منتشرشده قبلی را superseded می‌کند.
- بازیابی یک نسخه قدیمی همیشه draft تازه ایجاد می‌کند.
- نسخه منتشرشده حذف فیزیکی نمی‌شود.
- شناسه نسخه قالب با شناسه نسخه سند قرارداد متفاوت است.
