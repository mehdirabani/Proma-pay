# ویرایشگر قالب قرارداد

ویرایشگر از Quill محلی بسته استفاده می‌کند و CDN خارجی ندارد. حالت‌های ویرایش ساده، source و پیش‌نمایش در دسترس‌اند. تغییر بصری به `structured_html_v1` ذخیره می‌شود؛ حالت source می‌تواند `plain_text_v1` را حفظ کند.

امکانات شامل undo/redo داخلی Quill، عنوان، bold، emphasis، فهرست، متغیر، جستجو/جایگزینی، شمارش واژه، هشدار تغییر ذخیره‌نشده، کپی، بارگذاری قالب جاری و بازنشانی کنترل‌شده است.
