# بازسازی اسناد قرارداد

انتشار قالب جدید سندهای تولیدشده با نسخه قدیمی را `outdated_template` می‌کند. صف بازسازی در بسته‌های حداکثر 25تایی اجرا و قابل ادامه است.

قرارداد دارای نسخه سند `is_finalized = 1` از صف حذف می‌شود. خطاها در گزارش job ذخیره می‌شوند و style چاپ برای اعمال شدن نیاز به بازسازی ندارد.
