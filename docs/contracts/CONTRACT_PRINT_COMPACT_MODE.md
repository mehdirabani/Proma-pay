# حالت چاپ فشرده

پیش‌فرض V1.3.0:

- A4 عمودی
- حاشیه بالا 6mm
- حاشیه طرفین 10mm
- حاشیه پایین 10mm
- فونت 10.5pt
- line-height برابر 1.45
- فاصله پاراگراف 1.5mm
- فونت جدول 9.5pt
- padding سلول 1.2mm در 1.8mm

جدول می‌تواند بین صفحات ادامه پیدا کند؛ فقط ردیف عادی از شکستن جلوگیری می‌کند و `thead` در صفحه بعد تکرار می‌شود.
