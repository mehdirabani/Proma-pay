# ویرایشگر قالب قرارداد

حالت پیش‌فرض «ویرایش بصری» است. متن عادی قرارداد را مستقیماً ویرایش کنید و از
ستون متغیرها برای درج مقادیر پویا استفاده کنید. هر متغیر به‌صورت نشانه بنفش
محافظت‌شده نمایش داده می‌شود و هنگام ذخیره دقیقاً به شکل `{{...}}` ثبت می‌شود.

«پیش‌نمایش A4» فقط نمای محلیِ طرح است. برای مشاهده مقادیر نمونه و خروجی رسمی،
از «پیش‌نمایش داده نمونه» استفاده کنید. «HTML پیشرفته» برای کاربر آگاه است؛
کدهای ناامن و استایل‌های درون‌خطی در سمت سرور پذیرفته نمی‌شوند.

ذخیره فقط پیش‌نویس می‌سازد. انتشار و بازگردانی نسخه همچنان در صفحه نسخه‌ها با
ثبت دلیل و سابقه حسابرسی انجام می‌شود.
