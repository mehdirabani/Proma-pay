# استاندارد A4 قرارداد

هنگام چاپ:

1. اندازه A4 و scale 100% را انتخاب کنید.
2. browser header/footer را خاموش کنید.
3. preset compact فقط spacing و typography را تنظیم می‌کند و هرگز scale CSS اعمال نمی‌کند.
4. متن بندهای حقوقی نباید کوتاه یا حذف شود.
5. description قسط دلخواه در booklet به‌صورت کوتاه می‌آید؛ internal note چاپ نمی‌شود.

اگر داده استثنائاً بیش از ظرفیت A4 باشد، layout نباید overlap یا clip کند؛ صفحه دوم به‌جای scale غیرقابل‌خواندن ایجاد می‌شود.
