# Contract Print Settings

Contract output combines three independent records: legal-content version, contract data snapshot and print visual profile.

New print requests use the selected profile while historical legal text remains versioned. Header logo, centered title, contract number, date and customer/keeper metadata are rendered separately from the legal body. Compact A4 CSS controls typography, line height, table spacing and page breaks.

The mandatory release check uses a contract with two products and eight installments and verifies one A4 page without clipped signatures or unreadable legal clauses.
