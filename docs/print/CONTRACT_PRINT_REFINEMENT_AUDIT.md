# ممیزی چاپ قرارداد V1.3.9

## ساختار سربرگ

سربرگ print از سه بخش شماره قرارداد، لوگو و metadata تاریخ/مشتری تشکیل شده و عنوان در منطقه مستقل زیر آن قرار دارد. ساختار اطلاعات قرارداد حفظ شده است و سربرگ rounded و فشرده است.

## معیارهای چاپ

- A4 واقعی.
- scale مرورگر 100%.
- browser headers/footers خاموش.
- ممنوعیت `transform: scale` و `zoom`.
- متن body 7px و heading 8px در preset compact.
- جدول با padding کاهش‌یافته و line-height کنترل‌شده.

## سناریوی اجباری

دو محصول، هشت قسط، بندهای حقوقی فعلی و محل امضا باید یک صفحه A4 باشند. خروجی واقعی Chrome/Edge در گزارش QA ثبت می‌شود.
