# Mobile Calendar Design

Desktop keeps the month grid and agenda context. Mobile defaults to an agenda list instead of squeezing the month grid.

Mobile cards show date/time, event title, priority, status, assignee and countdown. Create/edit actions use a full-height panel with touch targets of at least 44 px. Stored installment events are excluded from the explicit-event query to prevent duplicates; reminder delivery uses a dedupe key per recipient and event.
