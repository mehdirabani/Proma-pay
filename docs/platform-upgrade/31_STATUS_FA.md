# وضعیت مرحله‌ای ارتقای پروما پی

آخرین به‌روزرسانی: ۱۴۰۵/۰۷/۱۱ (۲۰۲۶/۱۰/۰۳)

| مرحله | وضعیت | شواهد و کار باقی‌مانده |
| --- | --- | --- |
| شناخت کد و اسکیل‌ها | انجام‌شده برای مسیرهای بررسی‌شده | گزارش‌های `00_SOURCE_AUDIT.md` و `01_SKILL_REANALYSIS.md`. دو اسکیل تازهٔ امنیت و MySQL بررسی شدند. این نتیجه به معنی ممیزی کامل همهٔ کدها نیست. |
| صحت مالی و گردش رویدادها | در حال اجرا | آزمون متمرکز outbox و هم‌ارزی روند پرداخت ۲۴ مشتری در پایگاه QA دوباره پاس شدند. سناریوهای مالی انتها‌به‌انتها و دادهٔ هم‌اندازهٔ تولید هنوز کامل نشده‌اند. |
| کارایی | نتیجهٔ متمرکز ثبت‌شده | برای فهرست مشتریان، p95 زمان پاسخ HTTP در QA از ۴۳۹٫۹۹ به ۱۰۰٫۰۳ میلی‌ثانیه رسید؛ جزئیات در `25_PERFORMANCE_RESULTS.md`. سنجه‌های مرورگر و بار تولید باقی مانده‌اند. |
| ارتقای امن | پیاده‌سازی و آزمون متمرکز انجام‌شده | پیش‌بررسی فایل‌ها و migration، محدودیت اندازهٔ ZIP، قفل نصب، بازگردانی فایل پیش از شروع migration و وضعیت بازیابی پس از شروع آن اضافه شده‌اند. آزمون‌های مرتبط پاس‌اند. آزمون ارتقا و بازگردانی با پایگاه واقعی هنوز لازم است. |
| دروازهٔ QA محلی | پاس‌شده برای اجرای قبلی؛ اجرای gate بسط‌یافته در انتظار است | اجرای قبلی ۴۷۸ فایل PHP و ۸۵ اسکریپت را پاس کرد. تست‌های تازهٔ V2.0.4/Plugin اکنون در `tools/release-gate.php` ثبت شده‌اند؛ آزمون‌های DB این gate هنوز اجرا نشده‌اند. جزئیات در `30_RELEASE_GATE_STATUS.md`. |
| انتشار پایدار | تأیید نشده | نصب تازه و ارتقای بستهٔ نهایی، بازیابی واقعی پایگاه داده، آزمون مرورگر و دادهٔ هم‌اندازهٔ تولید، و دروازهٔ جداگانهٔ دسترس‌پذیری تولید هنوز باقی‌اند. گزارش `30_RELEASE_GATE_STATUS.md` جزئیات را دارد. |

**مرحلهٔ فعلی:** ZIPهای کاندید Core و Update برای V2.0.4 در `dist/candidates/v2.0.4/` ساخته شدند. بررسی ساختاری و checksum و PHP lint آرشیوها پاس شد، اما Release Gate کامل، نصب تازه، ارتقای بسته و restore واقعی هنوز اجرا نشده‌اند. این ZIPها انتشار پایدار نیستند و برای Production تأیید نشده‌اند. گزارش تاریخی Release Gate به اجرای قبلی مربوط است؛ gate گسترش‌یافتهٔ فعلی همچنان نیازمند محیط disposable است.
