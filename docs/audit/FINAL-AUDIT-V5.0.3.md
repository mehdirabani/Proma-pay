# ممیزی محدوده‌ای Candidate نسخه V5.0.3

تاریخ: ۲۰۲۶-۱۰-۰۹

## محدوده

بررسی تغییر شماره نسخه و ساخت بستهٔ differential ارتقا از V5.0.2 به V5.0.3؛ اصلاحات حقوقی و پرداختی V5.0.2 در این ساخت حفظ شده‌اند.

## شواهد و کنترل‌ها

- نسخهٔ برنامه در `config/version.php` برابر 5.0.3 است و نسخهٔ asset cache، `manifest.json` و `package.json` نیز با آن همسان شده‌اند.
- بستهٔ ارتقا با baseline دقیق V5.0.2 ساخته می‌شود و manifest آن باید `minimum_version: 5.0.2` را ثبت کند.
- تغییر دیتابیس جدیدی برای این نسخه تعریف نشده است.
- بسته Candidate است؛ بررسی نسخه و lint انجام می‌شود، اما آزمون‌های دیتابیس و گیت کامل انتشار در این ساخت اجرا نمی‌شوند.

## وضعیت شواهد

بسته‌بندی و checksum توسط اسکریپت‌های ساخت بررسی می‌شوند. این ساخت از درخت کاری فعلی با تغییرات قبلی ساخته می‌شود؛ source tree پاک نیست. هیچ ادعای آماده‌بودن برای production ثبت نمی‌شود.
