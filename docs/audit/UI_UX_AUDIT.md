# ممیزی UI/UX پرما پی

مشکلات اصلی مشاهده‌شده شامل فشردگی فرم‌ها، عرض‌های ثابت، اسکرول افقی صفحه قرارداد، اکشن‌های حقوقی پراکنده، کارت‌های مدال کشیده، مودال‌های وابسته به handler محلی و فضای خالی فوتر بود. معماری فعلی PHP server-rendered و Vanilla JS حفظ شده و اصلاحات از طریق توکن‌ها و کامپوننت‌های مشترک انجام می‌شود. حذف CSS قدیمی فقط پس از اثبات عدم استفاده مجاز است.

اولویت مهاجرت: پوسته و کنترل‌ها، قرارداد/اقساط، حقوقی، اپراتور، مشتری، تنظیمات و سپس پاک‌سازی کنترل‌شده است.
