## وضعیت Git و روش ممیزی

- `git fetch origin` با موفقیت انجام شد. `origin/main` و شاخه پاک‌سازی هر دو در SHA مبنا هستند و اختلاف commit ندارند.
- Checkout اصلی کاربر تغییرات محلی متعددی داشت: حذف محلی پوشه Laravel، تغییر فایل‌های افزونه `PromaSignConnect` و مسیرهای محلی `.appsec-forge/`، `backups/` و `storage/`. این موارد در Checkout اصلی باقی ماندند و ممیزی/کار اجرایی در worktree تمیز شاخه هدف انجام می‌شود.
- مقایسه فایل‌های ردیابی‌شده Git با نسخه مبنا انجام شد. پوشه `laravel/` در نسخه مبنا ۲۱۴ فایل ردیابی‌شده دارد.
- برنامه اصلی یک MVC سفارشی PHP با Router، مدل‌ها و Plugin Manager خود پروژه است. `package.json` ریشه صرفاً ابزار دسکتاپ Electron را تعریف می‌کند و Composer در ریشه وجود ندارد.

## مرز داده و قابلیت‌های محافظت‌شده

- جداول `ecommerce_*` در نصب‌های موجود حذف، خالی یا بازنویسی نمی‌شوند. حذف منطق برنامه به معنی حذف فیزیکی داده نیست.
- جداول، Migrationها و داده‌های قرارداد، ضمانت، اقساط، پرداخت، تسویه، حسابداری، کمیسیون، KYC و وصول مطالبات خارج از دامنه حذف هستند.
- در نصب تازه DDL و Seed فروشگاه اجرا نخواهد شد.
- هیچ کد یا تنظیم WooCommerce مستقلی در پلاگین‌های فعلی یافت نشد. افزونه‌های رسمی شریک/موجودی، Affiliate و Accounting به‌عنوان قابلیت‌های مستقل محافظت می‌شوند.

## برنامه اجرا و شواهد باقی‌مانده

1. این گزارش به‌عنوان Commit ممیزی ثبت می‌شود.
2. حذف Laravel و اصلاح Build/Docs جداگانه ثبت می‌شوند.
3. حذف Core فروشگاه و اصلاح Router/سرویس‌ها جداگانه ثبت می‌شوند.
4. پاک‌سازی UI و Asset، سپس نصب/دیتابیس و سازگاری Update در Commitهای مجزا انجام می‌شود.
5. تست ضدبازگشت به Release Gate افزوده می‌شود. Release Gate، lint و تست‌های static را اجرا می‌کند؛ تست دیتابیس، HTTP، Full Install، Upgrade، Backup/Restore و UI فقط با محیط QA ایزوله انجام می‌شوند و در نبود آن `NOT RUN` گزارش خواهند شد.
6. پس از هر مرحله نتیجه و SHA ثبت و Branch Push می‌شود. Merge به `main` تنها پس از بررسی diff و نتیجه gate انجام خواهد شد.
