# استاندارد قسط دلخواه

| داده | کاربرد | نمایش به مشتری |
| --- | --- | --- |
| `custom_title` | عنوان کوتاه عملیاتی | در صورت نیاز |
| `custom_description` | علت قابل فهم ایجاد قسط | بله، در صورت `customer_visible=1` |
| `internal_note` | جمع‌آوری، پیگیری یا نکته کارکنان | هرگز |
| `created_reason` | خلاصه دلیل ایجاد برای audit | فقط مدیریت |

توضیح مشتری نباید حاوی راهبرد حقوقی، نظر داخلی، شماره حساس یا اطلاعات مشتری دیگر باشد. یادداشت داخلی باید در ستون جداگانه ذخیره شود، نه داخل `notes` قابل مشاهده برای مشتری.
