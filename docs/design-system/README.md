# Proma Pay Design System

توکن‌های رنگ، فاصله، شعاع، سایه و ارتفاع کنترل‌ها در CSS مرکزی تعریف می‌شوند. سطح‌ها سفید یا خنثی روشن، بنفش فقط برای تأکید اصلی و رنگ‌های معنایی همراه متن وضعیت استفاده می‌شوند. فاصله‌ها بر مقیاس ۴، ۸، ۱۲، ۱۶، ۲۰، ۲۴، ۳۲، ۴۰ و ۴۸ پیکسل استوارند. کنترل و دکمه معمولی ارتفاع ۴۸ پیکسل دارد. شکست‌های هدف ۳۷۵، ۴۳۰، ۷۶۸، ۱۰۲۴، ۱۲۸۰، ۱۴۴۰ و ۱۹۲۰ هستند و RTL حالت پایه است.
