# فهرست کامپوننت‌ها

- Button: primary، secondary، success، danger، ghost و icon
- Form controls: input، select، textarea، date/time، money و file
- Card: base، metric، financial، status و action
- DataTable و mobile card list
- FilterBar و active chips
- StatusBadge
- Modal و drawer
- Tabs
- Timeline
- FileUploader
- EmptyState، Toast و Pagination

صفحات باید از کلاس‌های مشترک استفاده کنند و فرمول مالی یا مجوز را در قالب تکرار نکنند.
