# نگاشت کدهای HTTP

| کد | کاربرد |
| --- | --- |
| 400 | درخواست نامعتبر |
| 401 | نیاز به ورود |
| 403 | دسترسی رد شده |
| 404 | route یا منبع ناموجود |
| 405 | روش HTTP نامعتبر |
| 408/429 | timeout یا تلاش زیاد |
| 409/410/422 | conflict، منبع منقضی یا خطای validation |
| 413/415 | حجم یا نوع فایل نامعتبر |
| 419 | CSRF یا session منقضی |
| 500-504 | خطای داخلی یا سرویس وابسته |

تمامی این موارد header `X-Request-Id` و `Cache-Control: no-store` دارند.
