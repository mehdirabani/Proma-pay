# PROMA ACCOUNTING V1.1.0 IMPROVEMENT REPORT

1. **مشکلات قبلی UI:** padding کم، فرم بدون بخش، label مبهم، checkbox نامرتب و mobile ناقص.
2. **Padding صفحه:** 24px دسکتاپ، 19px تبلت و 13px موبایل.
3. **فاصله کارت:** padding برابر 22/19/15px و gap بخش 22/20/16px.
4. **Grid فرم:** شبکه 12 ستونه، دو ستون تبلت و تک‌ستون موبایل.
5. **هم‌ترازی input:** ارتفاع مشترک 44px و input group متصل.
6. **Checkbox:** از input متنی جدا و کل ردیف قابل کلیک شد.
7. **Switch:** keyboard، focus، touch، disabled و dark mode.
8. **نام‌گذاری:** عبارت‌های مبهم حذف و املای «کمیسیون» یک‌دست شد.
9. **مقدار پیش‌فرض:** واحد پویا درصد یا تومان و validation سمت سرور.
10. **مبنای پیش‌فرض:** کل قرارداد، تأمین مالی‌شده، سود و وصول‌شده.
11. **حداقل:** switch مستقل، مبلغ تومان و breakdown.
12. **حداکثر:** switch مستقل و validation حداقل ≤ حداکثر.
13. **گردکردن:** چهار روش و پنج واحد با integer math.
14. **ترتیب محاسبه:** قانون، مبنا، خام، حداقل، حداکثر، گردکردن، snapshot و ledger.
15. **Preview:** همان سرویس server-side فروش واقعی و بدون ذخیره.
16. **Wizard:** ده مرحله، ذخیره پیشرفت و ردکردن موقت.
17. **مرکز راهنما:** یازده بخش داخلی و بدون وابستگی اینترنت.
18. **شروع سریع:** راهنمای فارسی داخل پلاگین و docs.
19. **قواعد مانده:** پرداخت کاهش و دریافت افزایش را شفاف نمایش می‌دهد.
20. **Validation:** درصد، مبلغ، فروشنده، کف/سقف، مبنا، زمان و واحد گردکردن.
21. **حفاظت داده:** تغییر تنظیمات هیچ محاسبه تاریخی را بازنویسی نمی‌کند.
22. **Migration:** settingهای جدید و ستون‌های snapshot بدون حذف جدول یا رکورد.
23. **فایل‌های اصلاح‌شده:** provider، controller، CommissionService، Money، manifest، views و assets.
24. **فایل‌های جدید:** calculation service، migration، help، setup، tests، docs و builder.
25. **تست‌ها:** lint تمام PHPهای پلاگین، static قدیمی و V1.1، JS syntax، CSS scope، migration دوباره‌پذیر MariaDB، جریان واقعی preview/post/reverse و UI دسکتاپ، موبایل و dark mode.
26. **نتیجه تست:** migration داده نمونه را حفظ کرد؛ preview بدون write، ثبت idempotent و reversal با بازگشت دقیق مانده پاس شدند. کنترل‌ها 44px و overflow در تمام viewportهای آزمون صفر بود.
27. **شکست‌ها:** شکست محصول باقی نماند. کنترل اولیه توقف MariaDB زودتر از shutdown کامل اجرا شد و با polling صحیح تکرار و سرویس تمیز متوقف شد.
28. **ZIP:** `dist/plugins/PromaAccounting-v1.1.0.zip`.
29. **ارتقا:** بکاپ، بارگذاری ZIP، اجرای update، health check و بررسی preview.
30. **محدودیت:** تشخیص سود واقعی بر اساس جمع اقساط فعال منهای مبلغ تأمین مالی‌شده است؛ اقساط سفارشی لغوشده در آن وارد نمی‌شوند.
