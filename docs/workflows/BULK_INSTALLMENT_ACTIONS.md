# عملیات دسته‌جمعی اقساط

عملیات در صفحه جزئیات یک قرارداد انجام می‌شود و scope قرارداد از hidden input پذیرفته نمی‌شود؛ سرور شناسه‌ها را دوباره با قرارداد تطبیق می‌دهد.

عملیات مجاز شامل پرداخت گروهی، لغو، بازگردانی pending و محاسبه مجدد است. قسط پرداخت‌شده مستقیماً به status پرداخت‌شده تبدیل نمی‌شود. علت عملیات، snapshot قبل/بعد و actor در `installment_bulk_operations` و AuditLog ثبت می‌شود.
