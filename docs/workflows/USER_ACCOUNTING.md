# حسابداری کاربران

این ماژول دفتر داخلی کاربران است و ادعای حسابداری دوبل کامل ندارد. حساب‌ها در `accounting_user_accounts` و سندهای immutable در `accounting_ledger_entries` قرار دارند.

ثبت‌های افزایش: کمیسیون، هزینه قابل پرداخت، پاداش، دریافت از کاربر و افزایش دستی. ثبت‌های کاهش: پرداخت به کاربر، کسر و کاهش دستی. هر سند شامل مانده قبل/بعد و idempotency key است و اصلاح با reversal انجام می‌شود.
