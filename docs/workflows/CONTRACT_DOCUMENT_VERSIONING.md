# نسخه‌بندی سند قرارداد

هر قرارداد معتبر پس از ایجاد سند دارد. تولید مجدد پس از تغییر داده‌های قرارداد یک نسخه‌ی جدید در `contract_document_versions` می‌سازد.

نسخه‌ی منتشرشده برای مشاهده و چاپ استفاده می‌شود. نسخه‌ی نهایی‌شده بازنویسی خودکار نمی‌شود و تغییر بعدی باید با نسخه/الحاقیه‌ی جدید انجام شود. عنوان، header و body مستقل ذخیره می‌شوند و محتوای rich text پیش از ذخیره sanitize می‌شود.

مشتری فقط سند قراردادهای خودش را می‌بیند و مسیر چاپ نیز همان scope را در backend کنترل می‌کند.
