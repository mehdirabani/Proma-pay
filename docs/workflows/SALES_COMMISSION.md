# فروش و کمیسیون

رویداد `contract.created` فروش را با actor فعلی ثبت می‌کند. برای قراردادهای قدیمی، backfill فروشنده را حدس نمی‌زند و موارد ناشناخته را برای تخصیص دستی نشان می‌دهد.

قانون کمیسیون می‌تواند عمومی یا اختصاصی کاربر، ثابت یا درصدی، با مبنای اصل، مبلغ تأمین‌شده یا وصول‌شده باشد. کمیسیون موجودِ posted/paid بازنویسی نمی‌شود؛ تغییر فروشنده یا لغو قرارداد history و reversal ایجاد می‌کند.
