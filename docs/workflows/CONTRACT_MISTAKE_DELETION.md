# حذف قرارداد اشتباه

لغو قرارداد و حذف دائمی قرارداد دو عملیات جدا هستند.

حذف فقط برای ثبت آزمایشی، تکراری یا اشتباه است. سیستم قبل از حذف قرارداد را قفل می‌کند، پرونده حقوقی را بررسی می‌کند، snapshot قرارداد/اقساط/پرداخت‌ها/اسناد/لاگ‌ها را در `contract_deletion_archives` می‌نویسد و مشتری را حذف نمی‌کند.

اگر پرداخت مؤثر وجود داشته باشد، گزینه‌ی اصلاحیه‌ی scoped باید فعال شود. این اصلاحیه فقط پرداخت‌های همان قرارداد را صفر می‌کند و بازگشت وجه بانکی نیست. برای پرداخت زیبال تأیید جداگانه‌ی هشدار بانکی لازم است. قرارداد دارای سابقه حقوقی حذف دائمی نمی‌شود.
