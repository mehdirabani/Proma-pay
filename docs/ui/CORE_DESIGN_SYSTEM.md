# Core Design System

- Light gray application background and white content surfaces.
- Primary command color: purple; green/red reserved for positive/negative financial meaning.
- Control height and focus treatment are shared by inputs, selects and buttons.
- Required markers are attached to labels, not placed below controls.
- Cards use restrained radius and shadow; tables use clear row rhythm.
- RTL alignment, reduced-motion support, 44 px mobile targets and visible keyboard focus are mandatory.
- Header dropdowns expose semantic buttons and synchronized `aria-expanded` state.
