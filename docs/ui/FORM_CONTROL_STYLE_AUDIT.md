# ممیزی کنترل‌های فرم V1.3.9

## دامنه بررسی

- هسته: صفحه‌های ورود، مدیریت، اپراتور، وکیل، مشتری، تنظیمات، جست‌وجوها، فیلترها و مودال‌ها.
- افزونه‌های نصب‌شده: `PromaAccounting` و `PromaZarinpal`.
- کنترل‌های بومی: متن، جست‌وجو، تلفن، ایمیل، رمز، عدد، تاریخ، زمان، `textarea`، `select`، فایل، checkbox و radio.

## منابع تعارض پیش از اصلاح

| شناسه | منبع | ریشه مسئله | وضعیت |
| --- | --- | --- | --- |
| FORM-139-01 | selectorهای عمومی فرم | `input`های غیرمتنی می‌توانستند از ارتفاع و padding متن ارث ببرند. | PASSED: selector اکنون submit/button/reset/image را نیز مستثنا می‌کند. |
| FORM-139-02 | فرم‌های مودال و افزونه | border و radius در چند لایه تکرار می‌شد. | PASSED: tokens هسته اولویت دارد و CSS افزونه‌ها scoped است. |
| FORM-139-03 | focus مرورگر | حذف outline بدون جانشین خطر گم‌شدن focus داشت. | PASSED: پس‌زمینه سفید، خط داخلی پایین و سایه ملایم اعمال می‌شود. |
| FORM-139-04 | checkbox/radio | selector فیلد متنی نباید اندازه کنترل‌های انتخابی را تغییر دهد. | PASSED: selector جدا و focus قابل مشاهده دارند. |
| FORM-139-05 | file input | کنترل بومی فایل با فیلد متنی یکسان نیست. | PASSED: سطح بارگذاری با مرز dashed داخلی محدود و دکمه انتخاب فایل مجزا است. |

## قوانین نگه‌داری

- selector جهانی bare برای `input`، `select` و `textarea` ممنوع است.
- کنترل افزونه فقط زیر root همان افزونه تعریف می‌شود.
- `outline: none` فقط همراه indicator جایگزین مجاز است.
- border شفاف فقط برای جلوگیری از جابه‌جایی در focus مجاز است.
