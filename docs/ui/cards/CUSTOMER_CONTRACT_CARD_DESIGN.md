# استاندارد کارت مشتری و قرارداد

- فضای غیرتعاملی card مقصد جزئیات است.
- کنترل داخلی هرگز navigation card را trigger نمی‌کند.
- کارت قرارداد از grid responsive با حداقل عرض 300px استفاده می‌کند؛ در موبایل controls به ردیف مستقل می‌روند.
- عملیات icon-only local SVG، tooltip فارسی و نام قابل دسترس دارند.
- edit و delete در controls بالایی قرار دارند؛ عملیات مالی و چاپ در footer مستقل هستند.
