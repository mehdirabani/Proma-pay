# ممیزی کارت مشتری

کارت مشتری شامل آواتار، نام، موبایل، وضعیت، خلاصه قرارداد/معوق و عملیات است. منطقه غیرتعاملی card با `data-card-href` به جزئیات می‌رود و `a, button, input, select, textarea, label` از navigation خارج می‌شوند.

نکات پذیرفته‌شده:

- نام بلند wrap می‌شود و آواتار فشرده نمی‌شود.
- عملیات ویرایش/نمودار/تایم‌لاین نام قابل دسترس دارند.
- اطلاعات عملیاتی در یک کارت تکراری به dashboard تبدیل نشده‌اند.
- نتیجه viewport و keyboard: NOT EXECUTED تا تکمیل QA مرورگر.
