# ممیزی نوارهای فیلتر — نسخه ۱.۵.۵

## نقشهٔ اصلاح

| صفحه | الگوی نهایی | اقدام اصلی |
| --- | --- | --- |
| پرداخت‌ها | چهار فیلد تاریخ/قرارداد/مشتری + ناحیهٔ اقدام مستقل | اعمال فیلتر |
| مشتریان | جستجو، وضعیت، اقدام | اعمال فیلتر |
| کاربران | جستجو، نقش، وضعیت، واحد، اقدام | اعمال فیلتر |
| قراردادها | جستجوی گسترده + اقدام هم‌ردیف | جستجو |
| اقساط | فیلتر عملیاتی ۱۲ ستونه + فیلترهای پیشرفته | اعمال/پاک‌کردن |
| سررسید گذشته | فیلتر عملیاتی ۱۲ ستونه + وضعیت حقوقی و فیلترهای پیشرفته | اعمال/پاک‌کردن |

## قواعد

1. کنترل‌ها submit خودکار ندارند؛ تنها دکمهٔ مشخص فرم را ارسال می‌کند.
2. در دسکتاپ، grid دوازده‌ستونه استفاده می‌شود؛ در تبلت به سه/دو ستون و در موبایل به یک ستون تبدیل می‌شود.
3. ناحیهٔ دکمه‌ها کلاس مستقل دارد؛ به margin یا جای‌گذاری دستی وابسته نیست.
4. نوارهای وضعیت، شمارش و فیلترهای فعال در یک لایهٔ جدا از ورودی‌ها قرار دارند تا ارتفاع فرم را تغییر ندهند.
5. درخواست‌های Ajax موجود با محافظ ضدتکرار و محدودکنندهٔ درخواست سمت کاربر حفظ شده‌اند؛ این اصلاح هیچ polling یا submit جدیدی اضافه نمی‌کند.
