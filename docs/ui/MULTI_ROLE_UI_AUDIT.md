## موجودی مؤلفه‌های مشترک

- App shell، sidebar و topbar موجود با CSS مشترک RTL.
- `proma-page-intro`، `proma-kpi-grid` و `proma-stat-card` برای سربرگ و KPI.
- `proma-filter-card`، `proma-operational-filter` و `proma-filter-drawer` برای فیلترهای پایه و پیشرفته.
- `proma-status-tabs`، `render_pagination` و `proma-empty-state` برای فهرست‌های عملیاتی.
- `proma-row-actions` و `proma-action-menu` برای کم‌کردن تراکم دکمه‌ها.
- `proma-overdue-mobile-card` برای نمای موبایلی صف سررسید.

## نکات دسترس‌پذیری و واکنش‌گرایی

- فوکوس قابل رؤیت برای کنترل‌های صفحه با `:focus-visible` حفظ شده است.
- کنترل‌های فیلتر حداقل ۴۲px و دکمه‌ها حداقل ۴۴px در موبایل دارند.
- جدول اصلی سررسید در موبایل پنهان و با کارت جایگزین می‌شود؛ صفحه افقی مجبور به اسکرول نیست.
- فیلتر پیشرفته با `details/summary` بدون وابستگی به JavaScript قابل دسترسی است.

## موارد خارج از دامنه این انتشار

بازنویسی کامل همهٔ داشبوردها یا معماری افزونه‌ها انجام نشده است. تغییرات این انتشار، لایهٔ مشترک و صفحات با ایراد گزارش‌شده را اصلاح می‌کند و بنابراین صفحات موجود مدیریت، اپراتور، مشتری و حقوقی از زبان بصری مشترک بهره می‌برند، بدون تغییر نقش‌ها یا منطق مالی.
