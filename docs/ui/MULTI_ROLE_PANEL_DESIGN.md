# Multi-role Panel Design

The shared RTL shell provides one responsive sidebar, header, profile menu, notifications and role-derived navigation.

- Admin: financial summary, attention center, operations and quick actions.
- Operator: overdue queue, assigned contracts, promises and communication.
- Lawyer: legal cases, related contracts, costs and calendar.
- Customer: balance, contracts, installments, purchases and profile state.

Permissions remain server-side; hiding a menu item is not an authorization mechanism.
