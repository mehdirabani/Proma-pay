# Responsive and Modal Design System

## Breakpointها

- موبایل: کمتر از `768px`
- تبلت و ناوبری فشرده: کمتر از `992px`
- دسکتاپ: `992px` و بیشتر

## مودال

- دسکتاپ: کارت با حداکثر عرض 780px و ارتفاع 88dvh.
- موبایل: bottom sheet تمام‌عرض با حداکثر ارتفاع 92dvh و فضای امن پایین.
- هنگام بازبودن مودال، اسکرول صفحه بسته می‌شود.
- Escape، backdrop غیر static، Tab trap و بازگردانی focus پشتیبانی می‌شوند.

## فرم و جدول

- کنترل‌های هم‌ردیف `vertical-align: middle` دارند.
- در موبایل، footer مودال wrap می‌شود و دکمه‌ها حداقل ارتفاع لمس 44px دارند.
- جدول‌ها در wrapper کنترل‌شده horizontal scroll باقی می‌مانند؛ اطلاعات مالی حذف نمی‌شود.
