# اجزای فرم مشترک

## Field

هر فیلد باید در `label` یا `.proma-form-field` قرار بگیرد تا label، پیام کمک و نشانگر الزامی هم‌راستا بمانند. `initRequiredLabels()` ستاره را کنار label می‌گذارد، نه زیر input.

## Input group

`.proma-input-group` و `.input-group` یک سطح پرشده و یک focus مشترک دارند. پسوندهای `تومان` و `درصد` و دکمه‌های آیکنی نباید کادر مستقل بسازند.

## Select و جست‌وجوی Ajax

select بومی پیکان SVG محلی دارد. triggerهای live-search باید همان ارتفاع، رنگ و focus را بگیرند؛ پنل نتایج یک لایه شناور مستقل با shadow است و عمداً کادر خود را حفظ می‌کند.

## File

فایل input متن نیست. دکمه انتخاب فایل، نام فایل و پیام اعتبارسنجی در سطح نرم بارگذاری نمایش داده می‌شوند؛ dashed boundary فقط در همان کامپوننت مجاز است.

## انتخابی‌ها

checkbox و radio اندازه 18px و target لمسی label حداقل 44px دارند. focus آن‌ها shadow کوچک دارد تا با فیلد متنی اشتباه نشود.
