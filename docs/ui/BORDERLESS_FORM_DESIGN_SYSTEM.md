# سامانه فرم بدون کادر Proma Pay

## Tokenهای مرکزی

`assets/css/components/forms.css` تنها مرجع tokenهای فیلد است:

- ارتفاع: `44px`
- radius: `12px`
- حالت عادی: `#f7f7fa`
- hover: `#f2eff7`
- focus: سفید با accent داخلی بنفش
- خطا و موفقیت: accent داخلی رنگی همراه متن خطا، نه اتکا به رنگ تنها

## رفتارهای استاندارد

| حالت | رفتار |
| --- | --- |
| Normal | پس‌زمینه پرشده، border شفاف، بدون ring خارجی |
| Hover | تغییر ملایم پس‌زمینه |
| Focus | پس‌زمینه سفید، `inset 0 -2px 0` و سایه سبک |
| Disabled | خاکستری خوانا و cursor نامعتبر |
| Readonly | سطح متفاوت و بدون ابهام با فیلد قابل ویرایش |
| Invalid | پس‌زمینه بسیار کم‌رنگ قرمز، خط داخلی و پیام متنی |

## ممنوعیت‌ها

- border دائمی خاکستری یا بنفش دور کل فیلد.
- focus ring مستطیلی خارجی برای کنترل‌های متنی.
- استفاده از placeholder به‌جای label.
- تغییر height کنترل در focus.
