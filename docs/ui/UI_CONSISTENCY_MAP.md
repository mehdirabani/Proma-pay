# نقشهٔ یکپارچگی UI — نسخه ۱.۵.۵

## اجزای مشترک

| جزء | توکن/کلاس | مصرف‌کننده |
| --- | --- | --- |
| ابعاد و رنگ کنترل | `--ui-control-height`، `--ui-compact-control-height`، `--ui-*` | تمام فرم‌ها و مودال‌ها |
| فرم فیلتر | `proma-filter-toolbar` | پرداخت‌ها، کاربران، مشتریان، قراردادها |
| فیلتر عملیاتی | `proma-operational-filter` | اقساط و سررسید گذشته |
| اقدام‌های فرم/جدول | `proma-filter-actions`، `proma-table-actions` | فرم‌ها و لیست‌ها |
| مودال تماس | `#contact-directory` و `data-contact-directory` | اقساط و سررسید گذشته |
| کارت مدال | `proma-medal-grid` و `proma-medal-card` | مدیریت مدال‌ها |
| چاپ دفترچه | `booklet-print.css` | دفترچهٔ اقساط |

## ترتیب عملیاتی سایدبار

- مدیر: داشبورد، عملیات مالی، مشتری و قرارداد، پیگیری/پرداخت، حقوقی و بررسی، ارتباطات، فروشگاه، مدیریت سامانه.
- اپراتور: پیگیری سررسید، قراردادها، تقویم، اعلان‌ها، گفت‌وگو و فروشگاه.
- وکیل: داشبورد، پرونده‌ها، تقویم، اعلان‌ها، گفت‌وگو و فروشگاه.
- مشتری: داشبورد، قراردادها و اقساط، سوابق و ضمانت‌ها، خرید، ارتباطات.

## مرزهای تغییر

این نسخه فقط ساختار نمایش، دسترس‌پذیری و دادهٔ تماسِ موجود را یکپارچه می‌کند. احراز هویت، مجوزها، منطق محاسبات، درگاه و قراردادهای API تغییر نمی‌کنند.
