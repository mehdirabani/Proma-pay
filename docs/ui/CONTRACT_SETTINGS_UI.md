# رابط تنظیمات قرارداد

مسیر اصلی `settings/contracts` است و بخش‌های داشبورد، شماره‌گذاری، قالب، چاپ، نسخه‌ها، متغیرها، پیش‌نمایش و بازسازی را دارد. هر فرم action و CSRF مستقل دارد و هیچ secret یا تنظیم نامرتبط را submit نمی‌کند.

پیش‌نمایش A4 از همان renderer و profile چاپ استفاده می‌کند و داده واقعی مشتری را به‌صورت پیش‌فرض نمایش نمی‌دهد.
