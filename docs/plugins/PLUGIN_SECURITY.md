# امنیت افزونه

- فقط مدیر مجاز به نصب، فعال‌سازی، غیرفعال‌سازی و حذف افزونه است.
- بسته ZIP ابتدا در پوشه‌ی موقت استخراج و بررسی می‌شود.
- مسیرهای `../`، مسیر مطلق، symlink، `.env`، `config/database.php` و فایل‌های اجرایی مسدود هستند.
- فایل‌ها فقط داخل `plugins/{plugin-folder}` منتقل می‌شوند.
- route افزونه احراز هویت، CSRF برای POST و permission سمت سرور را رعایت می‌کند.
- داده‌های رمز، session، token، API key و password هرگز در event payload یا plugin log ثبت نمی‌شوند.
- حذف عادی داده‌های افزونه را پاک نمی‌کند. حذف کامل نیازمند تایید دقیق و permission ویژه است.
