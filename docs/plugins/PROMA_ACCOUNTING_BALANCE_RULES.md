# قواعد مانده حساب کاربران

| عملیات | اثر |
|---|---|
| کمیسیون | افزایش مانده |
| پاداش | افزایش مانده |
| هزینه قابل پرداخت | افزایش مانده |
| کسورات | کاهش مانده |
| پرداخت وجه به کاربر | کاهش مانده |
| دریافت وجه از کاربر | افزایش مانده |
| اصلاح | سند معکوس با اثر مخالف |

هر ثبت شامل مانده قبل و بعد است. `LedgerService` حساب را با `FOR UPDATE` قفل می‌کند و idempotency key از ثبت تکراری جلوگیری می‌کند. سند تاریخی مستقیماً ویرایش یا حذف نمی‌شود.
