# نصب افزونه

1. از دیتابیس و فایل‌های حساس backup بگیرید.
2. از مسیر «پلاگین‌ها» بسته ZIP معتبر را بارگذاری کنید.
3. نتیجه‌ی اعتبارسنجی Manifest و مسیرها را بررسی کنید.
4. روی «نصب» بزنید؛ migrationهای افزونه در `system_plugin_migrations` ثبت می‌شوند.
5. بعد از بررسی سلامت، افزونه را فعال کنید.

برای بروزرسانی، نسخه‌ی جدید باید Manifest سازگار و migrationهای جدید با نام یکتا داشته باشد. غیرفعال‌سازی menu و route را پنهان می‌کند اما داده‌های مالی و تاریخچه را نگه می‌دارد.
