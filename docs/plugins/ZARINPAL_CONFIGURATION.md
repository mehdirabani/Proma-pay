# پیکربندی زرین‌پال

- Merchant عملیاتی و آزمایشی را جداگانه ثبت کنید.
- برای سایت واقعی `production` و برای آزمون `sandbox` را انتخاب کنید.
- واحد پیشنهادی `IRT` است چون مبلغ داخلی Proma Pay تومان است.
- دامنه Callback باید HTTPS و دقیقاً هم‌دامنه با سامانه باشد.
- با «درگاه پیش‌فرض»، زرین‌پال انتخاب اولیه مشتری می‌شود.
- با «نمایش انتخاب درگاه»، مشتری می‌تواند بین زرین‌پال و زیبال فعال انتخاب کند.
- حداقل/حداکثر مبلغ و timeoutها را متناسب با قرارداد سرویس تنظیم کنید.

Callback نهایی:

`https://YOUR-DOMAIN/index.php?route=plugin/zarinpal/callback`

دامنه فوق باید در پنل زرین‌پال نیز مجاز باشد.
