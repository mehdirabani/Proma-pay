# تنظیمات کمیسیون Proma Accounting

قانون اختصاصی فروشنده بر قانون عمومی و تنظیمات پیش‌فرض مقدم است. مبنا یکی از کل قرارداد، مبلغ تأمین مالی‌شده، سود قرارداد یا مبلغ وصول‌شده است.

محاسبه با integer انجام می‌شود: مبلغ خام، حداقل، حداکثر و سپس گردکردن. درصد تا دو رقم اعشار و بین صفر تا صد معتبر است. حداقل فعال نباید از حداکثر فعال بزرگ‌تر باشد.

روش‌های گردکردن: بدون گردکردن، نزدیک‌ترین مقدار، رو به پایین و رو به بالا. واحدهای مجاز 100، 500، 1,000، 5,000 و 10,000 تومان هستند.

Preview از همان `CommissionCalculationService` فروش واقعی استفاده می‌کند و هیچ داده‌ای ذخیره نمی‌کند.
