# عیب‌یابی زرین‌پال

## درگاه در پنل مشتری دیده نمی‌شود

افزونه باید نصب و active باشد، گزینه فعال‌سازی روشن باشد و Merchant محیط انتخاب‌شده ثبت شده باشد.

## خطای دامنه Callback

آدرس پایه Callback را با HTTPS و همان hostname صفحه مدیریت ثبت کنید. reverse proxy نیز باید HTTPS را درست به PHP اعلام کند.

## request_uncertain

پاسخ قطعی از شبکه دریافت نشده است. درخواست تازه نسازید. ابتدا پنل زرین‌پال و صفحه تراکنش‌ها را بررسی کنید.

## verification_failed

از «بررسی مجدد» استفاده کنید. این عملیات Verify را با مبلغ و Merchant snapshot قبلی تکرار می‌کند و initiation جدید نمی‌سازد.

## کلید رمزنگاری پیدا نمی‌شود

فایل `storage/private/proma-zarinpal.key` را از بکاپ امن همان نصب بازیابی کنید. ساخت کلید تازه Merchantهای قبلی را قابل خواندن نمی‌کند.
