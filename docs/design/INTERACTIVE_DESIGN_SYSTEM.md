# سامانه طراحی تعاملی پروماپی

این صفحه مرجع فارسی و RTL برای توکن‌های طراحی، کامپوننت‌ها و الگوهای صفحهٔ Proma Pay است. صفحه مستقل از پوستهٔ عملیاتی سامانه رندر می‌شود و نمونه‌های مالی آن فقط دادهٔ ساختگی در مرورگر هستند.

## دسترسی و ساختار

مسیر داخلی: `index.php?route=design-system`؛ کنترلر دسترسی را برای نقش `admin` محدود می‌کند.

| فایل | مسئولیت |
| --- | --- |
| `config/design_system_catalog.php` | تعریف دسته‌ها، مستندات کامپوننت‌ها، الگوهای صفحه و زبان‌های کد |
| `controllers/DesignSystemController.php` | کنترل دسترسی، گردآوری نام آیکون‌های موجود و محاسبهٔ آمار |
| `views/design-system/index.php` | صفحهٔ مستقل، ساختار RTL و پنل‌های مستندات |
| `assets/css/pages/design-system.css` | ظاهر و رفتار واکنش‌گرای صفحه در محدودهٔ `ppds` |
| `assets/js/design-system.js` | جست‌وجو، پیش‌نمایش‌ها، کنترل‌ها، کد نمونه، تقویم، تم و تعامل‌ها |
| `tests/design_system_catalog_test.php` | بررسی شمارش، یکتایی و کامل‌بودن مستندات کاتالوگ |

نسخه از `config/version.php` خوانده می‌شود. آمار صفحه از خود کاتالوگ محاسبه می‌شوند؛ نمونه‌کدها برای هر مدخل در هفت زبان ساخته می‌شوند. React/TSX نمونهٔ جایگزین برای Integration است و به‌عنوان فناوری هسته معرفی نمی‌شود.

## افزودن یا ویرایش مدخل

مدخل را در گروه مناسب در `config/design_system_catalog.php` تعریف کنید. شناسه باید یکتا باشد. توضیح‌ها، کاربرد، Props، Events، States، دسترس‌پذیری، رفتار Responsive، Do/Don't و Related را نگه دارید. برای دسترسی از جست‌وجوی فارسی و انگلیسی، واژه‌های مترادف را به `aliases` اضافه کنید.

پیش‌نمایش بر اساس `family` در `assets/js/design-system.js` ساخته می‌شود. اگر نوع کامپوننت تازه‌ای اضافه شد، `renderPreview()` و کنترل‌های متناظر را نیز گسترش دهید. آمار از تعداد مدخل‌های کاتالوگ گرفته می‌شوند، بنابراین مقدارها را دستی و ثابت در View وارد نکنید.

## رفتار نمونه‌ها

- تغییرهای Playground فقط در حافظهٔ همان صفحه اعمال می‌شوند؛ داده‌ای به سرور یا پایگاه داده فرستاده نمی‌شود.
- تم و چند مورد اخیر فقط در `localStorage` همین مرورگر ذخیره می‌شوند.
- کد پنل متن است و اجرا نمی‌شود. گزینه‌های Copy، دانلود و انتخاب زبان به وضعیت فعلی نمونه وابسته‌اند.
- آیکون‌ها از فایل‌های Feather، stylesheetهای Font Awesome و Themify و helper آیکون Proma Pay خوانده می‌شوند.
- تقویم شمسی از `Intl.DateTimeFormat` مرورگر استفاده می‌کند.
- برای حفظ جداسازی CSS، کلاس‌ها و متغیرهای این صفحه باید در محدودهٔ `ppds` بمانند.

## کنترل کیفیت

```sh
node --check assets/js/design-system.js
php tests/design_system_catalog_test.php
```

در بررسی رابط، عرض‌های 360، 375، 390، 430، 768، 820، 1024، 1280، 1440 و 1920 پیکسل را پوشش دهید. تعامل‌های جست‌وجو، انتخاب مدخل، کنترل‌های Playground، زبان و کپی کد، تغییر تم، انتخاب تاریخ شمسی، بازوبسته‌شدن Modal با Escape و کلیک پس‌زمینه، و Drawerهای موبایل را نیز بررسی کنید.
