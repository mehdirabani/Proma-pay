# Proma Pay — Financial Domain

Version: 1.0

Status: Master Specification

Priority: CRITICAL

---

# معرفی

این فایل قوانین و ساختار کامل دامنه مالی (Financial Domain) پروژه Proma Pay را تعریف می‌کند.

تمام عملیات مالی پروژه باید مطابق این سند انجام شود.

هیچ محاسبه مالی نباید خارج از قوانین این فایل انجام شود.

---

# هدف

Financial Domain مسئول مدیریت موارد زیر است:

- کالا
- قرارداد
- پیش پرداخت
- مبلغ قابل تقسیط
- اقساط
- پرداخت
- جریمه
- پاداش
- تسویه
- هزینه‌های حقوقی
- مانده بدهی
- خلاصه مالی
- چاپ دفترچه
- چاپ قرارداد

---

# اصل طلایی

تمام محاسبات مالی فقط باید از طریق Serviceهای مالی انجام شوند.

هیچ Controller، View یا Model اجازه محاسبه مستقیم مبلغ را ندارد.

# Implementation Rules for Codex

قبل از تغییر Financial Domain:

□ Serviceهای مرتبط را بررسی کن.

□ Queryهای موجود را بررسی کن.

□ قوانین Business Rule را بررسی کن.

□ Notificationها را بررسی کن.

□ Calendar را بررسی کن.

□ Timeline را بررسی کن.

□ Logها را بررسی کن.

□ Reportها را بررسی کن.

□ RBAC را بررسی کن.

□ تست Regression انجام بده.

اگر هر تغییر باعث شکستن یکی از قوانین این فایل شود، ابتدا این سند باید به‌روزرسانی شود.

---

# Definition of Done

یک قابلیت مالی زمانی کامل است که:

✔ محاسبات صحیح باشد.

✔ تست شده باشد.

✔ مستند شده باشد.

✔ Timeline ثبت شود.

✔ Notification ارسال شود.

✔ Calendar به‌روزرسانی شود.

✔ Log ایجاد شود.

✔ RBAC رعایت شود.

✔ چاپ صحیح باشد.

✔ Responsive باشد.
