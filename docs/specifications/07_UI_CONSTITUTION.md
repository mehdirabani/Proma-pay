# معرفی

این فایل قانون اساسی رابط کاربری (UI Constitution) پروژه Proma Pay است.

تمام صفحات، فرم‌ها، مودال‌ها، کارت‌ها، جداول، دکمه‌ها و قابلیت‌های جدید باید مطابق قوانین این فایل طراحی شوند.

هیچ صفحه جدیدی نباید خارج از این استاندارد طراحی شود.

---

# فلسفه طراحی

رابط کاربری Proma Pay باید:

- ساده باشد.
- مدرن باشد.
- سریع باشد.
- مینیمال باشد.
- حرفه‌ای باشد.
- خوانا باشد.
- کاملاً RTL باشد.
- برای استفاده روزانه مناسب باشد.
- در استفاده طولانی باعث خستگی کاربر نشود.
