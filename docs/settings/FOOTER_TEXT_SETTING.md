# متن فوتر سامانه

کلید `footer_text` در تنظیمات عمومی مدیریت و footer layoutهای داخلی/عمومی استفاده می‌شود.

- مقدار پیش‌فرض: `پروما پی سامانه جامع پرداخت`
- طول بیشینه: 180 نویسه.
- ذخیره‌سازی: strip tag و فشرده‌سازی whitespace در سرور.
- migration فقط مقدار خالی یا مقدار پیش‌فرض تاریخی را به مقدار جدید تبدیل می‌کند؛ مقدار سفارشی مدیریت را تغییر نمی‌دهد.
- دکمه بازنشانی فقط مقدار پیش‌فرض را جایگزین می‌کند و با تعامل صریح مدیر اجرا می‌شود.
