# V1.5.8 Test Results

## نتیجه

گیت انتشار محلی در ۱۴۰۵/۰۵/۲۳ با محیط ایزولهٔ MariaDB و وب‌سرور PHP عبور کرد. این گزارش گواه دسترس‌پذیری محیط تولید نیست و برای انتشار عمومی، گیت availability مستقل لازم است.

## پوشش اجراشده

- PHP lint برای فایل‌های هسته و افزونه‌ها
- ۵۴ آزمون ایستا، واحد، امنیت، کنترل سیل درخواست، نشست هم‌زمان و ایزوله‌سازی افزونه
- ۱۵ آزمون یکپارچهٔ MariaDB: پرداخت، تسویه، جریمهٔ عادی/حقوقی، حقوقی، تغییر و ابطال قسط، هزینهٔ حقوقی و پیگیری سررسید
- آزمون اختصاصی `integration_legal_financial_summary_v158.php`: هزینهٔ ثبت‌شده ابتدا فقط «در انتظار تأیید» است، پس از تأیید به مبلغ قابل مطالبه و مبلغ نهایی امروز اضافه می‌شود.
- HTTP role smoke برای مدیر، اپراتور، وکیل و مشتری
- HTTP modal smoke، سنجش عملکرد داشبورد حسابداری و آزمون خطای افزونه

## نتیجهٔ کلیدی مالی

هزینهٔ حقوقی دیگر از مسیر نمایشی مستقل خوانده نمی‌شود. صفحهٔ حقوقی از `ContractFinancialSummaryService` و `ContractLegalCostSummaryService` استفاده می‌کند؛ بنابراین هزینهٔ تأییدشده در مبلغ قابل پرداخت امروز لحاظ و هزینهٔ در انتظار تأیید جداگانه نمایش داده می‌شود.
