# V1.5.9 Test Results

## نتیجه

گیت انتشار محلی V1.5.9 با نتیجهٔ `RELEASE_GATE_LOCAL_QA_OK_NOT_PRODUCTION_CERTIFIED` عبور کرد. آزمون‌ها روی یک پایگاه‌دادهٔ MariaDB کاملاً ایزوله و وب‌سرور PHP محلی اجرا شدند؛ هیچ داده، پیکربندی یا هاست تولیدی در این آزمون‌ها تغییر نکرد.

## محیط آزمون

- PHP: XAMPP PHP محلی با افزونهٔ ZipArchive
- Database: MariaDB 10.4.32، نمونهٔ موقت و ایزوله
- HTTP QA: `127.0.0.1:8123`
- نقش‌های آزمون: مدیر، اپراتور، وکیل و مشتری
- نسخهٔ مبنا برای delta: `PromaPay-v1.5.8.zip`

## آزمون‌های عبورکرده

- PHP lint برای 408 فایل هسته و افزونه‌ها
- آزمون‌های ایستا و واحد شامل دقت اعداد مالی، پاسخ خطا، کنترل سیل درخواست، نشست هم‌زمان، محدودسازی شبکه و ایزوله‌سازی خرابی افزونه
- آزمون‌های یکپارچهٔ MariaDB برای پرداخت، تسویه، مهاجرت، تغییر و ابطال قسط، هم‌زمانی مالی، پرونده و جریمهٔ حقوقی، تجمیع سررسید و حسابداری
- آزمون‌های HTTP برای نقش‌های مدیر، اپراتور، وکیل و مشتری، مودال‌ها و داشبورد حسابداری
- آزمون اختصاصی `integration_guarantor_document_v159.php` برای ضامن انتخابی موجود، ضامن دستی، snapshot تاریخی، عدم تکرار و یکسانی پیش‌نمایش/چاپ
- آزمون مرورگر واقعی محلی برای فهرست قراردادها، جزئیات قرارداد، خلاصهٔ مالی، کارت‌های پیگیری و صفحهٔ چاپ
- آزمون viewport در دسکتاپ و عرض 390px: ساختار قرارداد در موبایل تک‌ستونه شد، کنترل‌ها قابل دسترس ماندند و ستون خالی دائمی مشاهده نشد.

## پذیرش رفع ضامن

1. یک ضامن موجود به قرارداد متصل شد.
2. پس از تغییر نام پروفایل ضامن، قرارداد نخست همچنان snapshot قبلی خود را نگه داشت.
3. قرارداد جدید نام به‌روز ضامن را دریافت کرد.
4. ضامن دستی دوم با همان ترتیب در preview و print نمایش یافت.
5. تعداد جای امضاها برابر تعداد ضامن‌های نهایی بود.
