## محدودیت محیط

مرورگر داخل Codex دسترسی به URL محلی را با سیاست امنیتی رد کرد؛ بنابراین بازبینی تعاملی تصویری در این اجرا انجام نشد. حذف انتخاب‌گر قرارداد، wiring فرم‌ها، responsive CSS و ساختار HTML با تست‌های static و syntax پوشش داده شدند.
