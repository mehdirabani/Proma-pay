# نتایج آزمون Proma Pay V5.0.1 — Candidate

تاریخ اجرا: ۱۴۰۵/۰۷/۱۷ (۲۰۲۶-۱۰-۰۹)

## آزمون‌های پاس‌شده

- فرمان `php tools/release-gate.php --local --static-only` با نتیجهٔ `RELEASE_GATE_LOCAL_STATIC_UNIT_PASSED_INTEGRATION_BLOCKED` پایان یافت.
- `php -l` روی ۷۸۳ فایل PHP بدون خطای نحوی تمام شد.
- همهٔ آزمون‌های ایستا و واحد فهرست‌شده در گیت انتشار موفق شدند؛ از جمله آزمون‌های امنیت، بکاپ/بازیابی، پرداخت، افزونه‌ها و هم‌زمانی session.
- `tests/financial_v501.php`: صحت جمع چهار سبد اصل معوق، جریمه عادی، جریمه حقوقی و هزینه حقوقی.
- `tests/static_v501.php`: هم‌گامی نسخه، migration، idempotency و قفل پرداخت مرجع ثالث، تفکیک مانده مشتری/پرداخت مجموعه، جزئیات صف و خروجی تفکیکی.
- رگرسیون‌های مرتبط `static_v157.php`, `static_v158.php`, `installment_settlement_engine_v150.php` و `legal_penalty_projection_v156.php` پاس شدند.
- `git diff --check` روی فایل‌های این تغییر خطای whitespace نداشت؛ Git فقط هشدار معمول تبدیل پایان‌خط Windows را گزارش کرد.

## آزمون‌های اجرا‌نشده

- آزمون Integration دیتابیس برای اجرای migration، ساخت/تأیید هزینه، پرداخت جزئی، retry، برگشت پرداخت، هم‌زمانی دو اپراتور و تطبیق دفتر مشتری با دفتر پرداخت مجموعه اجرا نشد.
- آزمون نصب/ارتقا/rollback روی MySQL 5.7 یا MariaDB 10.3+ اجرا نشد.
- آزمون HTTP/E2E روی رابط واقعی و اجرای همهٔ سناریوهای بحرانی ۲۰‌گانه انجام نشد.
- متغیرهای `PROMA_TEST_DB_DSN`, `PROMA_TEST_DB_USER` و `PROMA_TEST_DB_PASSWORD` تنظیم نبودند. پیکربندی موجود به میزبان غیرمحلی اشاره می‌کند؛ برای جلوگیری از اتصال و تغییر دادهٔ واقعی، از آن استفاده نشد.

## نتیجه انتشار

نتیجهٔ این شواهد، Candidate با گیت ایستا/واحد موفق و گیت دیتابیس/عملیاتی باز است. نسخه Production-Ready نیست تا migration و سناریوهای مالی روی دیتابیس QA ایزوله اجرا شوند.
