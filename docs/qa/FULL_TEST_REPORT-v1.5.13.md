# Full Test Report — Proma Pay v1.5.13

## نتیجه

Release gate مربوط به این تغییرات با تست‌های ایستا، syntax check و اعتبارسنجی بسته‌ها انجام شد.

## تست‌های اجراشده

- PHP syntax check برای فایل‌های تغییرکرده.
- تست ایستای بارگذاری CSS ریدیزاین در layout.
- تست ایستای وجود selectorهای ضروری برای پنل‌های مدیریت، مشتری، اپراتور، حقوقی، مودال‌ها، سایدبار و responsive mobile.
- تست‌های قبلی پایداری ویرایشگر قالب قرارداد.
- اعتبارسنجی خروجی ZIP کامل و ZIP بروزرسانی.

## نکات QA

- این نسخه تغییر schema ندارد.
- بسته Core باید همچنان assetهای اصلی قالب را شامل شود؛ کاهش شدید حجم Core نشانه خطای بسته‌بندی است.
- بسته Update از 1.5.12 به 1.5.13 کوچک‌تر از Core است، چون فقط فایل‌های تغییرکرده را شامل می‌شود.
