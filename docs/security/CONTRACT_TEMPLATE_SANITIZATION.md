# امنیت قالب قرارداد

تگ‌های script، style، iframe، object، embed، form، input، button، link و meta حذف می‌شوند. event attributeها، URLهای JavaScript و inline style ذخیره نمی‌شوند.

HTML ساختاریافته فقط تگ‌های محتوایی، جدول و کلاس‌های تاییدشده قرارداد را حفظ می‌کند. placeholder ناشناخته در validation گزارش می‌شود و داده‌های قرارداد قبل از جایگزینی escape می‌شوند.
