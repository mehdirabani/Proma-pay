# Profile Change Approval

Users may update only their own avatar immediately. Avatar uploads accept validated JPEG, PNG or WebP images up to 5 MB with dimension and pixel limits; ownership is checked server-side.

Other permitted profile fields create a review request with the current-value snapshot. Management may approve all fields, approve selected fields, or reject the request. Conflicts caused by a later profile edit are exposed before application. Passwords are never stored in profile review payloads.
