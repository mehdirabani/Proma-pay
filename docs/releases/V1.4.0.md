# Proma Pay V1.4.0

## محور انتشار

- رفع خطای HTTP 500 پرداخت دستی از جزئیات قرارداد با اصلاح ناسازگاری امضای متد `PaymentRequest` با مدل پایه.
- جلوگیری هم‌زمان سمت سرور و مرورگر از ایجاد دوباره قرارداد با کلید idempotency تراکنشی.
- تغییر مستقیم آواتار برای همه نقش‌ها و نگه‌داری اصلاح سایر مشخصات در صف تأیید مدیریت.
- حذف کامل انتخاب‌گر قراردادها و رابط ویرایش دسته‌جمعی وابسته به آن.
- افزودن محدودسازی امن تلاش ورود، بدون تغییر قانون ورود مشتری با کد ملی و چهار رقم آخر موبایل.
- ترمیم ترتیب migrationهای موتور چاپ و افزودن schema نصب تازه برای کنترل‌های جدید.

## Migration

`database/migrations/2026_07_20_profile_auth_contract_payment_v140.sql` افزایشی و idempotent است. جدول‌های کنترل ورود و درخواست یکتای قرارداد را ایجاد، ستون‌های آرشیو قالب قرارداد را در نصب‌های قدیمی ترمیم و داده حساس احتمالی را از درخواست‌های در انتظار حذف می‌کند.
