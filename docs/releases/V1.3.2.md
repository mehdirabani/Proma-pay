# Proma Pay V1.3.2

این نسخه انتشار رابط مدرن افزونه Proma Accounting `1.2.0` و معماری بارگذاری محدود دارایی‌های پلاگین است.

## تغییرات اصلی

- بازطراحی کامل داشبورد، حساب کاربران، دفترکل، فروش، کمیسیون، قوانین، تنظیمات، راه‌اندازی و راهنما.
- بارگذاری CSS و JavaScript پلاگین فقط روی routeهای متعلق به همان پلاگین.
- جایگزینی Chart.js خارجی با نسخه محلی `4.4.7`.
- فرم‌های 44px، کارت‌های 16px، جدول دسکتاپ و کارت موبایل، حالت تاریک و مودال مالی قابل دسترس.
- حفظ کامل منطق مالی، مانده‌ها، کمیسیون‌ها و دو migration قبلی افزونه.

## بسته‌ها

- نصب کامل: `dist/core/proma-pay_v1-3-2.zip`
- بروزرسانی: `dist/updates/proma-update_v1-3-2.zip`
- manifest بروزرسانی: `dist/updates/proma-update_v1-3-2-manifest.json`
- پلاگین مستقل: `dist/plugins/PromaAccounting-1.2.0.zip`

پلاگین داخل ZIP هسته قرار نمی‌گیرد و باید از مدیریت پلاگین‌ها جداگانه نصب یا بروزرسانی شود.
