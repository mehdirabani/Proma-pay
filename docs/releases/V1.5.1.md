# Proma Pay V1.5.1

## اصلاح فوری پرداخت و هم‌راستایی رابط

- علت خطای `SQLSTATE[42000]: 1068 Multiple primary key defined` در migration تسویه شناسایی و رفع شد. جدول `settlement_quotes` در V1.5.0 هم کلید اصلی inline و هم کلید اصلی مستقل داشت؛ V1.5.1 فقط یک کلید اصلی تعریف می‌کند.
- اگر migration V1.5.0 ناموفق مانده باشد، نصب V1.5.1 همان migration را با تعریف درست دوباره اجرا می‌کند؛ بنابراین جدول و ستون‌های لازم برای پرداخت جزئی و تسویه ساخته می‌شوند.
- در گزارش پرداخت، wrapper دکمه‌های «مشاهده» و «اصلاحیه» از خود سلول جدول جدا شد تا تراز ستون‌ها در مرورگرهای Chromium و رابط RTL به‌هم نریزد.

## سازگاری

این بسته فقط برای سامانه‌ای است که V1.5.0 را دارد. اطلاعات کاربران، پرداخت‌های ثبت‌شده، `storage`، افزونه‌ها و `config/database.php` را تغییر نمی‌دهد.
