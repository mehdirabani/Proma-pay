# Proma Pay V1.4.3-rc.1

## Release status

This build is a release candidate. Stable publication remains blocked until production WAF/firewall evidence and the IP timeout regression gate pass.

## Fixed

- Administrators can permanently delete a contract with dependent internal history after two explicit confirmations, typed contract number, reason, and a complete pre-delete archive.
- Contract deletion no longer disables the confirmation inputs when dependencies exist.
- Internal database dependency keys are replaced with Persian operator-facing labels.
- Contract payment progress is calculated from paid amount and displayed as a high-contrast ring and percentage around the customer avatar.
- Profile change approvals have a dedicated admin sidebar page with pagination, filtering, field-level approval, conflict detection, rejection notes, and per-user history.
- Duplicate profile approval UI was removed from the users page.
- Medal cards now contain long criteria badges and actions at desktop and mobile widths.
- System Health was redesigned and now provides a privacy-safe diagnostic JSON bundle.
- Login throttling no longer locks every account behind a shared public IP. IP attempts remain observable while identifier and combined scopes retain protection.
- Required field markers, controls, action rows, and modal footers have consistent alignment.

## Upgrade

- From: V1.4.2
- To: V1.4.3-rc.1
- Database migration: none
- Optional plugins remain separately packaged.

## Safety

Permanent deletion does not refund Zibal or Zarinpal transactions. The archive and audit event are written inside the same database transaction before dependent rows are removed.
