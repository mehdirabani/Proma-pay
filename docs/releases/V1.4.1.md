# Proma Pay V1.4.1

V1.4.1 is a stabilization release for financial integrity, contract deduplication, plugin recovery and the multi-role experience.

## Highlights

- Central settled-installment guard and reconciliation service.
- Safe duplicate-contract review/repair with protected payment history.
- Unified plugin lifecycle, migration cursor safety and recovery UI.
- Partial profile approval and immediate secure avatar updates.
- Recipient-aware notifications, per-channel chat unread state and mobile calendar.
- Reversible medal evaluation/history/reconciliation.
- Fresh-install schema parity and removal of request-time DDL.
- Responsive browser coverage for admin, operator, lawyer and customer roles.
- Strict release gate, differential update manifest and canonical archive names.
- Correct payable-today allocation for single and grouped gateway payments.
- Verified one-page A4 output with two products and eight installments.
- Idempotent upgrade repair migrations for backup, ecommerce and contract document tables.
