# Proma Accounting V1.1.0

انتشار مستقل رابط و موتور تنظیمات حسابداری کاربران.

## تغییرات اصلی

- رابط RTL مشترک برای تمام صفحات پلاگین
- تنظیمات بخش‌بندی‌شده با واحد، مثال، switch و validation
- preview و محاسبه واقعی مبتنی بر یک سرویس واحد
- حداقل، حداکثر و گردکردن integer
- wizard ده‌مرحله‌ای و مرکز راهنمای داخلی
- جریان تأیید، ثبت یکتا و معکوس‌سازی کمیسیون
- migration محافظ داده‌های نسخه 1.0.0

## ارتقا

بکاپ بگیرید، `PromaAccounting-v1.1.0.zip` را بارگذاری و گزینه بروزرسانی پلاگین را اجرا کنید. هسته Proma Pay حداقل باید `V1.2.6` باشد. این بسته نباید داخل ZIP نصب هسته استخراج شود.
