# Proma Accounting 1.2.0

نسخه `1.2.0` بازطراحی کامل تجربه کاربری افزونه حسابداری کاربران است و به Proma Pay `V1.3.2` یا جدیدتر نیاز دارد.

## ارتقا

1. از دیتابیس و فایل‌ها بکاپ بگیرید.
2. هسته را با `proma-update_v1-3-2.zip` بروزرسانی کنید.
3. فایل `PromaAccounting-1.2.0.zip` را از مدیریت پلاگین‌ها بارگذاری و بروزرسانی کنید.
4. داشبورد، دفترکل، تنظیمات و یک عملیات پیش‌نمایش را بررسی کنید.

این نسخه migration جدید ندارد و مانده، فروش، کمیسیون، دفترکل و سوابق مالی را بازنویسی نمی‌کند.
