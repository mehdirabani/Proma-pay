# Proma Pay v1.5.13 Release Notes

## تمرکز نسخه

این نسخه ادامه اصلاحات 1.5.12 است و روی دیده‌شدن تغییرات ظاهری، بازگشت کامل استایل‌ها در بسته نصب کامل، و ایجاد یک زبان بصری مشترک برای پنل‌های مدیریت، مشتری، اپراتور و حقوقی تمرکز دارد.

## تغییرات اصلی

- افزودن لایه ریدیزاین مشترک برای کارت‌ها، فرم‌ها، جدول‌ها، مودال‌ها، سایدبار و داشبوردهای نقش‌محور.
- هماهنگ‌سازی ارتفاع کنترل‌ها، شعاع گوشه‌ها، فاصله‌ها و حالت‌های hover/focus.
- بهبود نمای کارت‌های قرارداد، مشتری، سوابق خرید، پیگیری سررسید و پنل‌های نقش‌محور بدون تغییر ساختار MVC.
- حفظ سازگاری بسته نصب کامل با assetهای قالب اصلی؛ فایل‌های CSS/JS/runtime قالب در خروجی Core باقی می‌مانند.
- نگه‌داشتن fallback سمت سرور برای ویرایشگر قرارداد تا در نبود JavaScript یا Quill، صفحه خالی نشود.

## مسیر ارتقا

- ارتقای مستقیم از نسخه 1.5.12 با بسته بروزرسانی v1.5.13.
- اگر سامانه روی نسخه‌های قدیمی‌تر مانند 1.5.10 یا 1.5.11 است، ابتدا بسته بروزرسانی 1.5.12 سازگار با آن نسخه نصب شود و سپس 1.5.13 اعمال گردد.
