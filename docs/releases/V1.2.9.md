# Proma Pay V1.2.9

انتشار پایدار رابط کاربری برای یک‌دست‌سازی فاصله‌ها و چیدمان همه سطوح دسترسی.

## تغییرات اصلی

- سیستم مرکزی spacing و layout برای صفحات داخلی، عمومی و احراز هویت
- اصلاح فاصله کارت‌ها و بلوک‌ها در پنل مدیریت، اپراتور، وکیل و مشتری
- gutter عمودی استاندارد برای داشبوردها، ردیف‌ها و گریدهای چندستونه
- حذف تداخل margin کارت قالب با gap شبکه
- چینش واکنش‌گرا با فاصله و padding متناسب برای دسکتاپ، تبلت و موبایل
- هم‌ترازی هدر کارت، actionها، جدول‌ها و وضعیت‌های خالی
- ورود اعلان‌های flash به ریتم اصلی صفحه
- تست ایستا و گزارش ممیزی UI برای جلوگیری از بازگشت باگ

## ارتقا

بسته `proma-update_v1-2-9.zip` برای ارتقا از `V1.2.8` ساخته می‌شود و مسیرهای عملیاتی `config/database.php`، `plugins/`، `storage/` و `uploads/` را حفظ می‌کند. برای نصب تازه از `proma-pay_v1-2-9.zip` استفاده شود.
