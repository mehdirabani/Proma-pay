# عملکرد V4.0.4

INSERTهای dump به‌صورت تراکنش‌های دسته‌ای وارد می‌شوند تا هر ردیف جداگانه به دیسک commit نشود. بکاپ InnoDB در snapshot مشترک گرفته می‌شود. در صورت وجود MyISAM، زمان dump نیازمند قفل خواندن همهٔ جدول‌هاست.

دو پردازش واقعی پرداخت با یک شناسه اجرا و یک تخصیص ثبت شد. sweep حساب‌ها با نرخ معمول تست ماشینی به محافظ نرخ برخورد کرد؛ فقط سرور QA با بودجهٔ موقت بیشتر اجرا شد. نرخ نصب اصلی تغییر نکرد.

benchmark جامع قبل/بعد برای latency، حافظه، query count و بار هم‌زمان عمومی این نسخه انجام نشده است؛ درصد بهبود سرعت ادعا نمی‌شود.
