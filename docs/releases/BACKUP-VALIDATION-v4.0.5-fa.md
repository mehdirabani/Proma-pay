## دسترسی از داخل سامانه

پس از بازیابی بکاپ تبدیل‌شده:

1. **تنظیمات ← بکاپ و بازیابی ← مشاهده همهٔ داده‌ها و سوابق قدیمی**.
2. جدول موردنظر را انتخاب کنید؛ صفحه‌های اول تا آخر و متن کامل فیلدهای بلند قابل مشاهده‌اند.
3. سوابق مشتریان، قراردادها، اقساط، پرداخت‌ها، پرونده‌های حقوقی، افزونه‌ها، فروشگاه قدیمی و تنظیمات در همین بخش قابل مشاهده‌اند. فایل‌های ثبت‌شده از بخش مدیریت فایل قابل دریافت‌اند.
4. دکمهٔ **دانلود اصل بکاپ** آرشیو مبدأ را با تمام فایل‌ها و metadata اولیه تحویل می‌دهد.

این صفحه فقط برای مدیر مجاز است. رمزها و کلیدهای اتصال در نمایش پوشانده می‌شوند؛ مقادیر اصلی در دیتابیس و بکاپ حفظ شده‌اند. صفحه امکان ویرایش یا حذف رکوردها ندارد.
