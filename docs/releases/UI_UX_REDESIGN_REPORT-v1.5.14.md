# گزارش UI/UX نسخه ۱.۵.۱۴

- اکشن‌های سریع حقوقی به فرم‌های یکپارچه و قابل استفاده در همان فهرست تبدیل شدند.
- محتوای اقساط و پرداخت در عرض کارت محصور شد تا اسکرول افقی کل صفحه ایجاد نشود.
- لاگ پرداخت قرارداد با ستون‌های تاریخ، قسط، نوع، روش، مبلغ، وضعیت و شناسه افزوده شد.
- فاصله‌گذاری، کنترل‌ها، کارت مدال، فوتر، مودال و واکنش‌گرایی با توکن‌های مشترک همگام شد.
- باز و بسته‌شدن مودال‌ها با event delegation مقاوم شد و شکست فیلتر AJAX به navigation امن برمی‌گردد.
- هیچ محاسبه مالی مرجع در JavaScript یا قالب تکرار نشده است.
