# Proma Pay V7.0.2 — Candidate

## Customer dashboard and purchase history

- The customer dashboard balance now sits on a high-contrast violet surface, with customer actions and next due details arranged in a responsive two-panel composition.
- Purchase history was rebuilt around the customer's contract records, with a real item summary, searchable contract number and item text, contract-status filtering, installment balance and progress, clear empty and no-results states, and pagination.
- Installment balance is computed from outstanding scheduled installments where available. Product names come only from recorded contract items; no sample purchase data is added.
- No database migration is included.
- Core version, PWA manifest, desktop package metadata, and asset cache version are synchronized at `7.0.2`.
- The update archive targets V7.0.1. Release gate status is `NOT_RUN`; authenticated customer-browser visual QA was unavailable in this build session.
