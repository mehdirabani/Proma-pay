# گزارش آزمون ضامن و مدارک V4.0.0

در این نسخه تغییر تازه‌ای در منطق ضامن یا مدارک قرارداد ثبت نشد. برای جلوگیری از پسرفت، آزمون‌های موجود روی دیتابیس QA تمیز اجرا شدند:

- رگرسیون مدارک ضامن قرارداد و پیوند فایل‌ها: موفق.
- ثبت و نمایش قرارداد/قسط روی schema نصب تمیز: موفق.
- خلاصهٔ مالی حقوقی و گردش هزینه‌ها: موفق.

اطلاعات و فایل‌های بکاپ در پایگاه‌دادهٔ اصلی دستکاری نشدند؛ آزمون migration فقط روی کپی QA اجرا شد.
