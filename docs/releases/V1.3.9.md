# Proma Pay V1.3.9

## محور انتشار

- سامانه یکپارچه فیلدهای filled و بدون کادر برای هسته، پنل مشتری، مودال‌ها و افزونه‌های نصب‌شده.
- بازطراحی ساختاری کارت قرارداد و تثبیت انتخاب دسته‌جمعی در جریان عادی layout.
- تفکیک توضیح قابل نمایش قسط دلخواه از یادداشت داخلی و ثبت migration سازگار.
- بهبود سربرگ و preset فشرده چاپ قرارداد و قابل‌ویرایش‌بودن متن footer.

## Migration

`database/migrations/2026_07_19_custom_installment_visibility_and_footer.sql` افزایشی و idempotent است. این migration ستون‌های قسط دلخواه را فقط در صورت نبودن اضافه می‌کند، توضیح‌های قدیمی را backfill می‌کند و footer سفارشی مدیر را تغییر نمی‌دهد.
