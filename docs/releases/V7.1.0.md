# Proma Pay V7.1.0 — Candidate

تاریخ ساخت: ۲۰۲۶/۱۰/۲۷

این نسخهٔ Core برای ارتقا از V7.0.4 در همین شاخه آماده شده است. وضعیت انتشار `candidate` است؛ گیت ایستا و واحد موفق شده، اما آزمون کامل پایگاه‌داده/HTTP و دسترس‌پذیری production تأیید نشده است.

## تغییرات

- آرشیو سوابق مشتری، مرکز تطبیق مالیِ تشخیصی، فضای عملیات وصول، نسخه‌بندی اصلاحیه‌های قرارداد و تحلیل ریسک سبد اعتباری به بستهٔ Core افزوده شدند. مسیر اصلاح اقساط از `syncInstallmentSchedule()` محافظت می‌کند و تشخیص مغایرت مجوز تغییر خودکار مانده نیست.
- مدیریت هزینه‌های حقوقی شامل تأیید هزینه توسط مدیریت، پرداخت ثبت‌شده به مرجع، بازپرداخت وکیل، تخصیص پرداخت‌ها و سابقهٔ ممیزی است.
- بررسی سازگاری افزونه‌ها تداخل مسیرهای ثابت و پارامتری را شناسایی می‌کند. نصب، ارتقا یا فعال‌سازی دو افزونهٔ دارای route مشترک مسدود می‌شود. در نصب‌های قدیمی که هر دو فعال بوده‌اند، Core راه‌اندازی پایدار را اولویت می‌دهد و افزونهٔ آزمایشی متعارض را به وضعیت خطا می‌برد.
- Proma Partnership Ledger به `2.0.0-alpha.4` ارتقا یافته و با Proma Inventory Partners ناسازگار اعلام شده است؛ اجرای هم‌زمان آن‌ها به‌دلیل routeها و جدول‌های مشترک مجاز نیست.
- مسیر قدیمیِ ریشه‌ای افزونهٔ WooCommerce از Core حذف و در فهرست حذف امنِ بستهٔ ارتقا قرار گرفته است. سورس جدیدِ افزونه زیر `plugins/` باقی می‌ماند؛ بستهٔ WooCommerce جداگانه و با کانال prerelease ساخته می‌شود.
- Snapshotهای محلی `backups/` و ZIPهای قالبِ نادیده‌گرفته‌شده در Core/Update قرار نمی‌گیرند.
- Core، PWA، service worker و نسخهٔ دارایی‌ها به V7.1.0 تغییر کردند. Plugin API روی 1.1 باقی ماند؛ شش افزونهٔ پایدار موجود نیازمند API تازه‌ای نیستند.

## بسته‌ها

- Core کامل: `dist/core/PromaPay-v7.1.0.zip`
- ارتقای تفاضلی از Core محلی V7.0.4: `dist/updates/PromaPay-Update-v7.1.0.zip`
- بستهٔ آزمایشی مستقل WooCommerce: `dist/plugins/pre-release/proma-pay-woocommerce/PromaPay-WooCommerce-v0.8.0-rc.6.zip`
- Proma Partnership Ledger یک افزونهٔ آزمایشی است و در Core کامل یا بستهٔ پایدار افزونه‌ها قرار نمی‌گیرد.

بستهٔ ارتقا با Manifest بازسازی‌شده از commit محلی V7.0.4 (`716d4582a06b57b14aaca91de3b93fa25466b2b8`) ساخته شده است. Updater پیش از نوشتن، checksum نسخهٔ قبلی را بررسی می‌کند و در صورت ناسازگاری نصب را متوقف و rollback می‌کند.
