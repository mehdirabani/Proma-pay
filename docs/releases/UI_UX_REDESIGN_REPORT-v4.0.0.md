# گزارش بررسی رابط Proma Pay V4.0.0

این انتشار بازطراحی سراسری رابط نیست؛ بررسی روی گردش‌کارهای موجود و نقاطی متمرکز بود که در QA باز شدند.

- صفحه ورود و مسیرهای داشبورد نقش‌های مدیر، اپراتور، وکیل و مشتری در درخواست HTTP پاسخ سالم دادند.
- مسیر داشبورد تعمیرکار پس از بروزرسانی افزونهٔ تعمیرات آزمایش شد؛ خطای ۵۰۰ ناشی از ارجاع namespace اصلاح شد.
- آزمون مودال قرارداد، CSS مشترک فیلدهای فرم و اسکریپت‌های modal/payment preview را دریافت کرد.
- نمایش RTL و دارایی‌های CSS/JavaScript در آزمون HTTP با مسیر درست فایل‌های ایستا بررسی شد.

**نتیجه:** آزمون‌های markup، دارایی و گردش‌کار HTTP پاس شدند. بازبینی دستی بصری در مرورگرِ نشست زنده جزو این اجرا نبود.
