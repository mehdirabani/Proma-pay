# Proma Pay V1.3.0

انتشار معماری تنظیمات قرارداد، نسخه‌بندی قالب و موتور چاپ فشرده.

## امکانات

- تنظیمات مستقل قرارداد و actionهای ذخیره مجزا
- قالب مؤثر، پیش‌نویس، انتشار، بازگردانی و تاریخچه نسخه‌ها
- انتقال بدون تخریب قالب قدیمی به نسخه منتشرشده شماره 1
- ویرایشگر محلی با حالت ساده، source، متغیر، کپی و هشدار تغییرات
- renderer سازگار با متن ساده و HTML ساختاریافته پاک‌سازی‌شده
- profile چاپ مرکزی و presetهای فشرده، استاندارد و خوانا
- پیش‌نمایش A4 با داده نمونه و renderer واقعی
- حاشیه بالای 6mm و line-height پیش‌فرض 1.45
- ادامه جدول بزرگ بین صفحات و تکرار table header
- صف بازسازی 25تایی با حفظ اسناد نهایی

## ارتقا

بسته `proma-update_v1-3-0.zip` برای ارتقا از `V1.2.9` است. migration جداول نسخه قالب، audit، صف بازسازی و فیلدهای ارتباط نسخه سند را ایجاد می‌کند. قبل از ارتقا بکاپ کامل تهیه شود.
