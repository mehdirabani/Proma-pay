# Proma Pay V2.0.0 Release Notes

Proma Pay V2.0.0 is a major UI and customer-portal release prepared from the current Core source.

## Highlights

- Added the V2 responsive RTL shell assets: `assets/css/components/v2-system.css` and `assets/js/v2-system.js`.
- Kept the legacy runtime template assets in the installer so the full Core package keeps the expected production size and visual dependencies.
- Added role-aware layout classes and mobile quick navigation for management, operator, legal, and customer users.
- Added configurable customer dashboard banners with admin management, secure image upload, scheduling, sorting, and activation controls.
- Added the customer banner migration and installer seed so a fresh installation has a visible default customer banner.
- Updated the customer dashboard to render managed banners from the server.
- Updated reset and upload helpers so portal banner storage is handled explicitly.
- Added a V2 static regression test to protect the new shell, managed banners, responsive CSS, and release version metadata.

## Upgrade Notes

- The differential update package is built from the verified V1.5.14 full installer manifest.
- The update preserves `config/database.php`, `storage/`, uploaded files, and installed plugin directories.
- Run the update from the system updater on an installation that reports V1.5.14 as its current Core version.
- For older installations, upgrade to V1.5.14 first or use the full V2.0.0 installer for a fresh installation.

## Database Changes

- Adds `portal_banners` through `database/migrations/2026_09_21_customer_portal_banners_v200.sql`.
- The installer schema also includes the table and default customer dashboard banner.

## Notes

- This release does not remove Bootstrap/Cuba runtime assets. Full Bootstrap-to-Tailwind migration remains a separate V2.0.1 task so V2.0.0 stays installable and compatible with the current production layout.
