# Proma Pay V1.3.1

V1.3.1 is the contract-print stabilization release following V1.3.0.

- Adds the official one-page compact A4 profile and applies it to existing print documents.
- Adds safe inline and full-paragraph `**important clause**` markup.
- Adds live page-count and space diagnostics using the real renderer and stylesheet.
- Adds reference-aware template version deletion, archival, restore-as-draft, permissions, and audit events.
- Groups every installed plugin under one sidebar submenu.

Upgrade from V1.3.0 using `proma-update_v1-3-1.zip`. The updater runs `2026_07_13_contract_print_compact_version_retention.sql` and preserves `config/database.php`, `plugins/`, `storage/`, and uploads.
