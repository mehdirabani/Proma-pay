# Proma Pay 2.0.1

Maintenance release for the V2 shell. Update baseline: the published full 2.0.0 archive.

- Replace template sidebar control that overwrote product shell classes with role-preserving Vanilla navigation.
- Native keyboard-operable menu buttons, mobile backdrop, Escape, focus return and focus containment.
- Remove duplicate modal closer; keep the existing financial form modal lifecycle.
- Remove custom scrollbar scripts from the authenticated shell; use native scrolling.
- Unify brand aliases, reduce decorative effects, improve mobile touch targets and dialog scrolling.
- Refresh mobile labels when table rows arrive dynamically, without additional HTTP requests.
- Remove duplicate bottom spacing and refresh asset/service-worker versions.

This release does not claim completion of the full next-generation redesign or Tailwind migration. The audited roadmap is in docs/design/NEXT_GENERATION_EXECUTION.md. Financial rules and database version are unchanged.

Installation: back up the site/database, upload PromaPay-Update-v2.0.1.zip through Settings → Update on 2.0.0. Use the full installer only for a clean installation. The differential package intentionally omits unchanged fonts/styles, which remain included in the full archive.
