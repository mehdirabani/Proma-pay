# Proma Pay 2.0.3

Patch release for installations on Proma Pay 2.0.2. The full Core archive is a complete installer; the separate Update archive is differential and targets the verified 2.0.2 Core archive.

## Changes

- Made the V2 navigation menu independently scrollable while keeping the brand and role header fixed, so bottom navigation entries remain reachable on short screens.
- Fixed narrow-screen data-card sizing so customer and contract names keep a usable text column instead of wrapping one character per line.
- Removed mobile horizontal overflow caused by long normal/legal penalty descriptions and struck-through comparison amounts; descriptive values now wrap inside their card.
- Added a real-browser mobile regression suite covering customer installments and dashboard, admin dashboard/contracts/contract details, and the sidebar at 320, 360, 375, 390 and 430 CSS pixels.
- Bumped asset cache keys to 2.0.3 so installed 2.0.2 browsers request the corrected styles.

## Install

For an existing 2.0.2 installation, upload `PromaPay-Update-v2.0.3.zip` through Settings → Update. Keep a current database and file backup first. Use `PromaPay-v2.0.3.zip` only for a new installation or controlled full reinstall. Do not upload the full installer as an update package.

Verification results and limitations are in `FULL_TEST_REPORT-v2.0.3.md`. Local QA does not certify a production host's custom CSS, proxy cache, PHP configuration or customer data.
