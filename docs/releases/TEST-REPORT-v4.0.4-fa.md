آزمون مالی روی رکوردهای ساختگیِ clone انجام شد. بکاپ قدیمی روی دیتابیس اصلی restore نشد. نخستین sweep بسیار سریع کاربران به محدودیت نرخ درخواست برخورد کرد؛ اجرای دوم با بودجهٔ موقت بیشتر فقط برای سرور QA موفق بود. محدودیت نرخ نصب اصلی تغییر نکرد.

## شاهد و روش بازتولید

- `tools/qa_restore_payments_v404.php` برای ZIP واقعی و خطاهای SQL/فایل، با guard نام دیتابیس مستقل.
- `tests/integration_payment_retry_v404.php` و `tests/integration_payment_race_v404.php` برای rollback، retry و رقابت واقعی.
- `tests/integration_installment_settlement_v150.php` و `tests/integration_gateway_reconciliation_v204.php` برای اصلاح و callback.
- `tests/http_v4_all_users_backup_smoke.php` برای sweep همهٔ حساب‌ها با حفظ وضعیت اولیهٔ حساب‌ها.
- `tools/qa_update_v404.php` و `tools/qa_update_local_v404.php` برای نصب واقعی بسته و اثر انگشت داده.
- تصویر پیام موفقیت فرم پرداخت: `docs/audit/screenshots/v404-payment-success.png`.

## حدود نتیجه

کل گیت integration گستردهٔ پروژه، همهٔ نسخه‌های تاریخی بکاپ، همهٔ مرورگرها، پرداخت واقعی بانکی، قطع برق واقعی و بار تجمیعی اجرا نشده‌اند. موفقیت این آزمون‌ها اثبات مسیرهای فهرست‌شده است؛ Production Ready برای کل سامانه ادعا نمی‌شود.
