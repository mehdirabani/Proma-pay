# Proma Pay V1.5.13

## خلاصه انتشار

نسخه 1.5.13 ادامه بسته اصلاحی 1.5.12 است و برای رفع نگرانی‌های زیر آماده شده است:

- نصب کامل نباید صفحه خام، ساده یا بدون استایل تحویل دهد.
- تنظیمات پیشرفته قرارداد باید fallback قابل مشاهده داشته باشد و در صورت مشکل JavaScript خالی نماند.
- پنل‌های مدیریت، مشتری، اپراتور و حقوقی باید زبان بصری منسجم‌تری داشته باشند.
- بسته بروزرسانی باید فقط تغییرات لازم را حمل کند، اما بسته Core کامل باید assetهای قالب را نگه دارد.

## تغییرات فنی

- افزودن فایل `assets/css/components/role-redesign.css`.
- بارگذاری ریدیزاین مشترک در layout اصلی.
- افزایش نسخه برنامه به 1.5.13.
- اضافه شدن تست ایستای `tests/static_v1513_role_redesign.php`.

## وضعیت سازگاری

- بدون migration جدید.
- سازگار با ساختار lightweight MVC فعلی.
- بروزرسانی از 1.5.12 به 1.5.13 طراحی شده است.
