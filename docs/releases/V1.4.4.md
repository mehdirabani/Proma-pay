# Proma Pay V1.4.4

این نسخه بر کاهش بار هاست، جلوگیری از صف شدن درخواست‌های هم‌زمان و هماهنگی رابط‌های مدیریتی تمرکز دارد.

## تغییرات اصلی

- قفل نشست PHP پس از احراز هویت زودهنگام آزاد می‌شود و نوشتن‌های flash، سبد خرید، کد تأیید و sandbox در بازه کوتاه و کنترل‌شده انجام می‌شوند.
- polling اعلان‌ها میان تب‌های باز هماهنگ شده، timeout و backoff دارد و در حالت آفلاین یا تب پنهان فشار کمتری ایجاد می‌کند.
- feed اعلان‌ها read-only شده و از سه query و یک UPDATE دوره‌ای به دو query خواندنی کاهش یافته است.
- تله‌متری درخواست‌های عادی نمونه‌برداری می‌شود و قفل فایل آن non-blocking است.
- فرم حذف قرارداد از endpoint کم‌ریسک‌تر `contracts/retire` استفاده می‌کند و endpoint قبلی فقط برای سازگاری باقی مانده است.
- صفحات «تأیید اصلاح مشخصات» و «سلامت سامانه» دیگر با هدر ثابت قالب تداخل ندارند.
- گزارش فنی امن برای ارائه به پشتیبانی هاست افزوده شده است.
- مودال‌های موبایل با visual viewport، صفحه‌کلید نرم‌افزاری و چینش تک‌ستونه هماهنگ شده‌اند.
- ردیف‌های فرم مودال در نمایشگرهای کوتاه دیگر فشرده یا روی هم افتاده نمی‌شوند و بدنه مودال مستقل اسکرول می‌شود.
- نصب‌کننده قبل از بکاپ و اجرای migration نسخه بسته را کنترل می‌کند؛ نسخه یکسان، قدیمی یا ناسازگار دکمه نصب ندارد.
- migration نسخه ۱.۴.۳ بدون حذف لاگ احراز هویت اصلاح شده تا ارتقا از ۱.۴.۳ به ۱.۴.۴ به‌درستی انجام شود.
- بکاپ ایمنی دیگر cache، session، لاگ، بسته‌های بروزرسانی و فایل‌های release را دوباره داخل خود جمع نمی‌کند؛ در نتیجه سبک‌تر و پایدارتر است.
- بسته نصب کامل فقط فایل‌های لازم runtime را دارد؛ قالب مرجع، تست‌ها و ابزارهای توسعه در GitHub حفظ شده‌اند اما داخل ZIP نصب قرار نمی‌گیرند.

## نکته هاست

خطای `ERR_CONNECTION_TIMED_OUT` بدون کد HTTP پیش از اجرای PHP رخ می‌دهد. این نسخه عامل‌های تحریک‌کننده داخل برنامه را کاهش می‌دهد، اما رفع blacklist موجود در CSF/LFD، ModSecurity، WAF یا فایروال فقط با بررسی لاگ و تنظیمات هاست ممکن است.
