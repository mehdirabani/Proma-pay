# گزارش امنیت Proma Pay V4.0.3 — Candidate

## کنترل‌های بررسی‌شده

- گیت ایستا/واحد محلی شامل rate-limit/secrets، مدیریت نشست، ابطال نشست هنگام تغییر رمز، امنیت Zarinpal و plugin route guard بود؛ همه‌ی تست‌های تعریف‌شده در این گیت پاس شدند.
- فهرست مشتریانِ داده‌گیری‌شده hash رمز را در view یا فیلدهای projection نمی‌گیرد؛ گزارش دیتابیس قبلی این رفتار را به‌صورت source review ثبت کرده است.
- تغییر رمز مشتری با POST محافظت‌شده از CSRF (`onlyPost()`)، نقش customer، بررسی رمز جاری و ذخیره‌ی `password_hash()` انجام می‌شود؛ پس از تغییر fingerprint نشست بازتولید می‌شود. تغییر و audit داخل تراکنش هستند.
- migration حالت رمز، hash هیچ مشتری را بازنویسی نمی‌کند. حالت همه‌ی مشتریان موجود که مقدار جدید ندارند `pin` می‌شود؛ ورودهای پیش‌فرض همچنان چهار رقم پایانی موبایل را می‌پذیرند.
- ورود قدیمی و رمز شخصی روی کپی QA از طریق UI آزمون شدند. رمزها یا شناسه‌های مشتری در این گزارش ثبت نشده‌اند.

## محدودیت ممیزی

این کار تست نفوذ کامل نیست. آزمون‌های پویا برای CSRF/IDOR همه‌ی endpointها، race/replay پرداخت، uploadها، secret scanning جامع، security headerهای تمام routeها، plugin install/update و sandbox مرورگر انجام نشده است. فاز integration release gate و test runtime چندمرورگری اجرا نشدند. «همه تست‌های محلی پاس شدند» فقط به مجموعه‌ی static/unit پیکربندی‌شده اشاره دارد.

گزارش محلی قبلی `docs/audit/security/live-audit-2026-10-07.md` موارد و محدودیت‌های نقش‌ها را ثبت می‌کند؛ آن گزارش جای ارزیابی نهایی Candidate را نمی‌گیرد. پیش از انتشار، dependency advisoryهای Electron و کل زنجیره‌ی build باید با lockfile فعلی دوباره ارزیابی شوند.

## ریسک باقیمانده

در پایگاه اولیه‌ی QA، بخشی از hashهای قدیمی با PIN چهاررقمی جاری منطبق نبودند. رفتار ورود برای مشتری در کد بر اساس PIN compatibility است و hashهای موجود عمداً بازنویسی نشده‌اند؛ بنابراین سازگاری کاربر حفظ می‌شود ولی hashهای قدیمی ممکن است با سیاست جاری هم‌خوان نباشند. رمز شخصی اختیاری این حالت را فقط برای کاربری که خودش تغییر رمز را انجام دهد اصلاح می‌کند.

## نتیجه

تغییر رمز مشتری و hash آن آزمون شده، اما release امنیتی تأیید نشده است؛ آزمون کامل integration، تست پویا و بازبینی نهایی بسته‌ی Candidate لازم است.
