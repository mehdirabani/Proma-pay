# Proma Pay V1.4.2-rc.1

Release channel: `rc`. Stable publication: `BLOCKED`.

This diagnostic candidate addresses application-side availability amplifiers found during the timeout incident investigation. It does not claim that the hosting-level timeout or reported IP blocking is solved because the affected IP, firewall/WAF rule, worker metrics and production security logs were not supplied.

## Changes

- Added request IDs, structured request timing, query profiling, plugin spans and protected daily telemetry.
- Kept `health/live` independent from database, plugins and sessions; expanded `health/ready` with database, migration, queue, storage and Core checks.
- Added a protected administrator system-health page.
- Bounded and consolidated Accounting dashboard queries, added justified covering indexes and isolated widget failures.
- Released the PHP session lock before Accounting widget reads.
- Added connect/total timeouts and TLS safeguards to Zibal, IPPanel, OpenRouter and Zarinpal clients.
- Replaced fixed frontend polling with non-overlapping adaptive polling, cancellation and backoff.
- Added non-blocking Cron locks and bounded outbox processing.
- Returned controlled HTTP 429 responses for login lockouts.
- Added availability, performance, database, network, security, plugin-failure and HTTP regression tests.
