# Proma Pay V1.5.11

This patch stabilizes the professional contract-template settings page after
the visual editor rollout.

- Decodes route names before selecting route-scoped assets, so encoded URLs
  such as `settings%2Fcontracts%2Ftemplate` still load the contract editor.
- Renders the visual editor shell from PHP and lets JavaScript enhance it,
  reducing the chance of exposing raw HTML during editor startup.
- Fixes editor mode state so preview, visual editing and advanced HTML mode do
  not look active at the same time.
- Tightens the contract editor canvas spacing and document-like editing area.

Update baseline: V1.5.10.
