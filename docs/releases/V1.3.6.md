# Proma Pay V1.3.6

## محور انتشار

- مدیریت متمرکز خطاهای HTML و JSON با شناسه پیگیری، کد وضعیت صحیح و عدم افشای مسیر، SQL یا trace.
- fallback استاتیک برای خطاهای 500 و 503 و مستند پیکربندی Apache/Nginx.
- محاسبه مبلغ با عدد صحیح تومان و نرخ درصد با دقت ثابت چهار رقم اعشار در مسیرهای مالی هسته.
- انتقال hook و اعلان قرارداد، قسط و رسید پرداخت به `system_outbox` پس از commit.
- حذف تغییر schema هنگام اجرای درخواست عادی در مدل‌های مالی اصلی.
- الگوی واکنش‌گرای مودال با focus management، scroll lock و bottom sheet موبایل.
