# موارد باقی‌مانده V4.0.4

مشکلات مشخص بازیابی قدیمی، recovery خطا و retry پرداخت اصلاح و آزمون شدند. سازگاری ارتقای نصب محلی نیز بسته شد.

| اولویت | مورد باز |
|---|---|
| P0 | حال‌شدن اقساط آینده به رویداد مستند با مبنای قراردادی، سند و تایید نیاز دارد؛ مسیر جامع آن هنوز تایید نشده است |
| P0 | وصول اجرای حکم و مختومه‌سازی حقوقی به تطبیق مستقل و E2E کامل نیاز دارد |
| P1 | تمام integrationهای مأموریت گسترده، تمام مرورگرها و بار هم‌زمان عمومی اجرا نشده‌اند |
| P1 | همهٔ قواعد منفی، سقف‌ها، بازه‌ها و رویدادهای جبرانی وفاداری تکمیل/تایید نشده‌اند |
| P1 | بازیابی همهٔ قالب‌های تاریخی و قطع برق واقعی آزمون نشده؛ پس از توقف ناگهانی، recovery مدیریتی از بکاپ ایمنی لازم است |
| P2 | تعریف KPI داشبورد و صف معوقات به یکسان‌سازی محصولی نیاز دارد |
| P2 | نصب، ارتقا و rollback عملی همهٔ افزونه‌ها در یک ماتریس کامل تایید نشده‌اند |

این موارد مانع ادعای Production Ready برای کل سامانه‌اند. بستهٔ ۴.۰.۴ برای دموی محلی نصب و مسیرهای اولویت‌دار آن با شواهد واقعی تایید شده‌اند.
