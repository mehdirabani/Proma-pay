# Proma Pay V1.3.7

## محور انتشار

- تثبیت چرخه لغو و حذف قرارداد با نگه‌داری سوابق مالی و حقوقی.
- تکمیل schema نصب تازه برای metadata لغو قرارداد و repair سازگاری installer.
- اجرای idempotent migration چرخه عمر قرارداد و ثبت وضعیت قابل بازیابی در updater.
- مسیرهای health مستقل از session و plugin boot و fallbackهای خطای استاتیک.
- بارگذاری امن محتوای HTML در ویرایشگر Quill قرارداد، بدون نمایش تگ‌های HTML به کاربر.
- یکپارچگی نسخه در هسته، PWA manifest و service worker.

## سازگاری

- نسخه هسته: `1.3.7`
- نسخه نمایشی: `V1.3.7`
- حداقل نسخه برای بسته بروزرسانی: `1.3.0`
- PHP آزموده‌شده: `8.2.12`
- MariaDB آزموده‌شده: `10.4.32`

## Migration

`database/migrations/2026_07_18_contract_lifecycle_schema_repair_v137.sql` به‌صورت idempotent ستون‌های لغو قرارداد و قسط، اصلاحیه پرداخت و جدول‌های audit، archive، document و outbox را ایجاد یا ترمیم می‌کند.

## راهنمای نصب

برای نصب تازه از `install.php` استفاده کنید. برای ارتقا، فایل `proma-update_v1-3-7.zip` را از بخش بروزرسانی سامانه بارگذاری و نصب کنید. این بسته فایل‌های حساس `config/database.php`، `storage/`، `uploads/` و `plugins/` را حفظ می‌کند.
