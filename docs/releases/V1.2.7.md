# انتشار V1.2.7

نسخه‌ی canonical این اصلاح `1.2.7` و نسخه‌ی نمایشی آن `V1.2.7` است.

## تغییرات

- سایدبار در دسکتاپ viewport مستقل دارد و آخرین آیتم آن با padding انتهایی قابل اسکرول است.
- فرم‌های استاندارد سامانه از ارتفاع پایه‌ی مشترک برای label و کنترل استفاده می‌کنند.
- علامت الزامی به ابتدای label منتقل شده و دیگر زیر input نمایش داده نمی‌شود.
- حذف دائمی قرارداد در کارت‌ها به آیکن کنار ویرایش در بالای چپ منتقل شده است.
- حذف دائمی در نمای لیست نیز به کنترل icon-only تبدیل شده است.
