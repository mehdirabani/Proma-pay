# UI/UX Redesign Report — Proma Pay v1.5.13

## محدوده

یک لایه مشترک تجربه کاربری به سامانه اضافه شد که روی چهار نقش اصلی اثر می‌گذارد:

- مدیریت
- مشتری
- اپراتور
- وکیل / واحد حقوقی

## اصول اعمال‌شده

- حفظ ساختار فعلی و سبک بودن سامانه.
- استفاده از tokenهای موجود و فاصله‌های استاندارد.
- یکپارچه‌سازی فرم‌ها، دکمه‌ها، کارت‌ها و جدول‌ها.
- کاهش حس صفحه خام یا بدون استایل در بسته نصب کامل.
- بهبود خوانایی در RTL و صفحه‌های فارسی.
- رعایت responsive برای موبایل و تبلت.

## اجزای تحت پوشش

- داشبوردهای نقش‌محور
- کارت‌های مشتری و قرارداد
- سوابق خرید مشتری
- کارت‌های پیگیری و سررسید
- فیلترها و فرم‌های جستجو
- جدول‌های عملیاتی
- مودال‌ها و footerهای عملیاتی
- سایدبار و آیتم‌های فعال
- ویرایشگر تنظیمات قرارداد و fallback نمایشی
