# Proma Pay V1.5.12

This patch fixes two release-blocking issues reported after V1.5.11:

- Fresh full installations now include the full runtime asset tree for the RTL
  template, excluding only source maps. This restores the expected visual
  styling and supporting template assets on clean installs.
- The professional contract-template editor now renders a server-side document
  preview inside the visual canvas and keeps the advanced source textarea
  available as a JavaScript failure fallback.

Update baseline: V1.5.11.
