# Proma Pay V1.5.10

See `RELEASE_NOTES-v1.5.10.md`. This patch makes the contract editor
visual-first, adds protected variable insertion and local A4 layout preview,
and scopes contract tabs to their component instance.

The packaged core includes the runtime RTL styles, responsive stylesheet,
fonts, Quill editor and required local JavaScript assets. Operational data,
uploads, configuration, test fixtures and development documentation are
intentionally excluded from the installer and must remain on the target host.

Upgrade from 1.5.9 with the single `PromaPay-Update-v1.5.10.zip` package. The
update manifest checks its exact baseline before applying files and does not
replace `config/database.php`, uploaded files, logs, sessions or plugins.
