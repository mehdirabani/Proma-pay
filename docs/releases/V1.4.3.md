# Proma Pay V1.4.3

نسخه V1.4.3 یک انتشار تثبیتی برای حذف امن قرارداد، دسترس‌پذیری ورود، صف تأیید مشخصات و یکپارچگی رابط مدیریت است.

## تغییرات اصلی

- مدیر می‌تواند قرارداد آزمایشی یا اشتباهی را با انتخاب صریح پاک‌سازی تاریخچه حذف کند. پیش از حذف، snapshot کامل قرارداد و وابستگی‌ها در بایگانی غیرقابل ویرایش ثبت می‌شود.
- پرداخت‌های درگاهی یک تأیید مستقل دارند و رابط به‌وضوح اعلام می‌کند که حذف رکورد، بازگشت وجه بانکی انجام نمی‌دهد.
- کمیسیون‌ها و اسناد ثبت‌شده افزونه حسابداری پیش از پاک‌سازی معکوس می‌شوند؛ اگر سرویس حسابداری در دسترس نباشد، حذف برای حفظ مانده‌ها متوقف می‌شود.
- محدودسازی ورود دیگر IP مشترک را به‌تنهایی مسدود نمی‌کند و فقط شناسه کاربر و ترکیب شناسه/IP را کنترل می‌کند.
- تأیید اصلاح مشخصات به فضای کاری مستقل مدیریت با جست‌وجو، فیلتر، صفحه‌بندی، تأیید جزئی، رد، قفل تعارض و تاریخچه حساب منتقل شده است.
- حلقه درصد تسویه کارت قرارداد بازگردانده شده و چیدمان مدال‌ها، badgeها، عملیات و متن‌های بلند در دسکتاپ و موبایل اصلاح شده است.
- صفحه سلامت سامانه با زبان بصری اصلی Proma Pay، وضعیت سرویس‌ها، افزونه‌ها و تله‌متری ایمن بازطراحی شده است.
- پشتیبانی از تنظیم اتصال دیتابیس با متغیرهای محیطی برای استقرار امن‌تر و تست مستقل اضافه شده است.
- ساختار مشترک مودال‌ها بازنویسی شده است: هدر و فوتر ثابت، بدنه محدود و اسکرول‌پذیر، ردیف‌های خودکار و لیبل‌های صریح از تداخل فیلد، textarea و متن راهنما جلوگیری می‌کنند.
- پیش‌نمایش پرداخت فقط هنگام بازشدن مودال همان قسط درخواست می‌شود. جستجوها و پیش‌نمایش‌های GET تکراری با کش کوتاه‌مدت محدود، لغو درخواست قبلی و جلوگیری از ارسال دوباره فرم کنترل می‌شوند.

## بروزرسانی دیتابیس

فایل `database/migrations/2026_07_22_release_v143.sql` قفل‌های قدیمی مبتنی بر IP خالص را حذف و ایندکس صف بررسی مشخصات را به شکل idempotent اضافه می‌کند.

## سازگاری

- حداقل PHP: 8.1
- مسیر بروزرسانی مستقیم: V1.4.2 یا جدیدتر
- افزونه حسابداری همراه: V1.2.5
- داده‌های عملیاتی `config/database.php`، `plugins/` و `storage/` در بسته بروزرسانی حفظ می‌شوند.

## آزمون انتشار

- ۲۹۲ فایل PHP بدون خطای syntax بررسی شدند.
- مسیرهای HTTP مدیر، اپراتور، وکیل و مشتری و تست اختصاصی مودال قسط روی MariaDB واقعی پاس شدند.
- تست‌های مالی، امنیت، timeout، session lock، افزونه حسابداری و زرین‌پال و مسیر degraded بدون خطا تکمیل شدند.

## نکته دسترس‌پذیری

اصلاح نرم‌افزاری قفل IP در این نسخه انجام شده است. مسدودی‌های لایه هاست، WAF، ModSecurity، فایروال، DNS یا ظرفیت PHP-FPM خارج از کد برنامه‌اند و برای تأیید نهایی محیط عملیاتی باید با لاگ‌های همان سرور بررسی شوند.
