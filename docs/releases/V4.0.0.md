# یادداشت انتشار Proma Pay V4.0.0

**وضعیت:** کاندید انتشار محلی (Candidate)  
**تاریخ:** ۱۴۰۵/۰۷/۱۴ — ۶ اکتبر ۲۰۲۶  
**مبنای بستهٔ بروزرسانی:** V3.0.2

## تغییرات

- مهاجرت سازگاری بکاپ‌های قدیمی برای تکمیل ستون‌های درخواست پرداخت و outbox؛ داده‌های موجود حذف نمی‌شوند.
- بازیابی مسیر افزونه‌های فعال از پوشهٔ نصب فعلی پس از جابه‌جایی/بازیابی بکاپ.
- جلوگیری از ورود مشتری با رمز کوتاه‌تر از ۸ نویسه؛ مشتریانی که رمز قدیمی کوتاه دارند باید از بازیابی رمز استفاده کنند.
- رفع خطای داشبورد تعمیرکار و رفع نام مستعار رزروشدهٔ `manual` در گزارش مدال‌ها برای MySQL 8.4.
- اجرای موفق آزمون‌های پرداخت، تسویه اقساط، هزینه‌های حقوقی، فایل‌ها، صندوق رویدادها، سطح دسترسی، نقش‌ها و بروزرسانی افزونه.

## نصب و سازگاری

فایل بروزرسانی تفاضلی V4.0.0 برای نصب‌های V3.0.2 ساخته شده است. قبل از نصب، نسخهٔ پشتیبان خودکار را بررسی کنید. عملیات ZIP در PHP به افزونهٔ `ZipArchive` نیاز دارد؛ پس از فعال‌کردن آن در PHP لارگون، Apache باید دوباره راه‌اندازی شود تا تنظیم جدید بارگذاری شود.

این بسته آزمون محلی را گذرانده است؛ گیت دسترس‌پذیری و زیرساخت تولید اجرا نشده و این Candidate گواهی انتشار Production ندارد. سازگاری PromaSignConnect با Core بالاتر از `tested_core_max=1.5.5` با این گیت ادعا نمی‌شود.
