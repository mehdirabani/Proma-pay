# Proma Pay V1.4.7

این نسخه برای پایداری سامانه روی هاست‌های اشتراکی منتشر شده است. تمرکز آن کاهش تعداد queryها، حذف نوشتن‌های غیرضروری در درخواست‌های نمایشی، و جلوگیری از اشغال هم‌زمان workerهای محدود PHP و MySQL است.

## اصلاحات اصلی

- صفحه «قراردادها» به‌جای اجرای query جدا برای هر کارت، آمار اقساط، نمودار شش‌ماهه پرداخت، تایم‌لاین، ضامنان و داده‌های فرم‌های ویرایش را به‌صورت گروهی دریافت می‌کند.
- تعداد کارت‌های هر صفحه به ۱۲ محدود شد؛ حالت جدول همچنان ۲۴ رکورد در هر صفحه نمایش می‌دهد. این تفاوت به این علت است که کارت‌ها مودال‌ها و داده‌های بیشتری دارند.
- فهرست و جزئیات قرارداد دیگر هنگام مشاهده، وضعیت همه قراردادهای سامانه را update نمی‌کنند. پس از ثبت یا اصلاح پرداخت فقط وضعیت همان قرارداد همگام می‌شود.
- پیش‌نمایش لغو و حذف دائمی قرارداد lazy است: فقط زمانی که مدیر همان مودال را باز کند، اطلاعات وابستگی‌ها از سرور خوانده می‌شود. اعتبارسنجی نهایی حذف همچنان در سمت سرور انجام می‌شود.
- عملیات seed و نرمال‌سازی settings از مسیر هر درخواست خارج و به migration انتقال یافت؛ بنابراین باز شدن صفحه دیگر روی جدول settings نوشتن انجام نمی‌دهد.
- ایندکس‌های `legal_cases(contract_id, status)` و `payments(contract_id, status, is_corrected, id)` برای مسیرهای فهرست قرارداد و پرداخت اضافه شد.

## روش بروزرسانی

از پنل بروزرسانی داخلی، فایل `PromaPay-Update-v1.4.7.zip` را نصب کنید. migration همراه بسته بدون حذف داده اجرا می‌شود. پس از پایان، یک‌بار Ctrl+F5 بزنید تا JavaScript جدید دریافت شود.

این نسخه فشار برنامه را کم می‌کند؛ اما اگر حتی `health-static.txt` از بیرون timeout شود، آن مورد همچنان باید از سوی سرویس‌دهنده هاست برای وب‌سرور، فایروال و پورت‌های 80/443 رفع شود.
