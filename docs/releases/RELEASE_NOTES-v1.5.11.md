# Release Notes - Proma Pay V1.5.11

## Fixed

- Contract professional settings now load the template-editor assets even when
  the route arrives URL-encoded.
- The template editor now starts from a server-rendered visual shell instead of
  relying on a late-created editor container.
- Preview mode no longer leaves the advanced HTML tab visually selected.

## Changed

- Refined the contract-template editing canvas so it reads more like a
  controlled document workspace and less like a raw source editor.
