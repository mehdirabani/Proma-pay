## گیت انتشار

تا زمان بسته‌شدن هر دو مورد P0 و اجرای گیت integration، نسخه Production Ready نیست. هیچ اصلاحی روی داده‌ی واقعی مشتری برای بستن این موارد مجاز/انجام‌شده نیست.

ارتقای موفق clone تمیز فقط سازگاری بسته با baseline رسمی V4.0.2 را نشان می‌دهد و به معنی سازگاری با نصب محلی driftدار نیست. نصب فعال همچنان V4.0.2 است.
