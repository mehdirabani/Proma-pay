# Proma Pay V1.3.4

تاریخ انتشار: 2026-07-13

## دامنه انتشار

- افزوده شدن رجیستری درگاه‌های پرداخت به هسته بدون حذف یا تغییر قراردادهای عمومی زیبال.
- عرضه افزونه مستقل `PromaZarinpal 1.0.0` بر پایه API رسمی v4 زرین‌پال.
- پشتیبانی از پرداخت یک قسط، چند قسط، callback بدون session، sandbox و production.
- ذخیره امن Merchant ID با AES-256-GCM و جلوگیری از ثبت PAN کامل یا secret در لاگ‌ها.
- پردازش idempotent پاسخ‌های `100` و `101` و جلوگیری از پرداخت و اعلان تکراری.
- گزارش تراکنش‌ها، CSV، retry کنترل‌شده، health check و انتخاب درگاه در پنل مشتری.
- رفع تداخل شناسه رهگیری تخصیص‌های پرداخت گروهی.

## سازگاری

- حداقل PHP افزونه: `8.1`
- Plugin API: `1.0`
- حداقل هسته برای افزونه: `1.2.6`
- نسخه افزونه زرین‌پال: `1.0.0`
- زیبال و مسیرهای قدیمی آن همچنان قابل استفاده هستند.

ابتدا هسته را به `V1.3.4` بروزرسانی کنید، سپس ZIP افزونه را از مدیریت پلاگین‌ها نصب و فعال کنید. Merchant ID محیط عملیاتی و آزمایشی مستقل‌اند و callback باید روی HTTPS عمومی در دسترس باشد.
