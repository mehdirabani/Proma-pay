# Proma Pay 2.2.1 release candidate

Date: 2026-10-05  
Status: local candidate package; production release gate not run

## Changes

- Restore accepts recognizable Proma Pay SQL dumps in older ZIP layouts without requiring one exact metadata file.
- Installer controls load the shared color tokens, and core button colors have fallbacks for pages that omit the token sheet.
- Legacy customer credentials shorter than eight characters can start a restricted password-upgrade session; customer routes remain blocked until a new password is saved.
- The cache asset version changes to `2.2.1`.

## Artifacts

- Core installer: `core/PromaPay-v2.2.1.zip`
- Full Core and plugin bundle: `core/PromaPay-Full-v2.2.1.zip`
- Default update from the available Core baseline: `updates/PromaPay-Update-v2.2.1.zip`
- Direct update from Core `2.0.10`: `updates/PromaPay-Update-v2.2.1-from-v2.0.10.zip`

These files are local candidate artifacts. The release gate and a real backup restore/customer login on an installed database were not run.
