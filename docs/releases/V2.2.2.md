# Proma Pay 2.2.2 release candidate

Date: 2026-10-05  
Status: local candidate package; production release gate not run

## Changes

- Customers can sign in with their account identifier and the last four digits of the registered primary mobile number. Existing personal passwords continue to work.
- Public customer registration no longer asks the customer to create a complex password; the stored password hash remains random and independent from the mobile PIN.
- Customer password recovery accepts a four-character PIN. Staff password recovery retains the eight-character minimum.
- Login throttling remains enabled for failed identifier/IP attempts.

## Artifacts

- Core installer: `core/PromaPay-v2.2.2.zip`
- Full Core and plugin bundle: `core/PromaPay-Full-v2.2.2.zip`
- Default update from the available Core baseline: `updates/PromaPay-Update-v2.2.2.zip`
- Direct update from Core `2.0.10`: `updates/PromaPay-Update-v2.2.2-from-v2.0.10.zip`

These files are local candidate artifacts. The release gate and customer login on a real installed database were not run.
