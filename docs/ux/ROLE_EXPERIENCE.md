# تجربه نقش‌ها

- مدیریت: سلامت مالی، تأیید هزینه، قراردادها و کنترل عملیات.
- اپراتور: صف تماس، خلاصه بدهی، نتیجه تماس و پیگیری بعدی.
- وکیل: پرونده، مرحله، اقدام، هزینه، ضمیمه و مهلت در یک گردش سریع.
- مشتری: مبلغ قابل پرداخت، قسط بعدی، پرداخت، سابقه و پشتیبانی بدون جزئیات داخلی.

داده و مجوز سمت سرور مرجع است؛ تفاوت رابط نقش‌ها صرفاً مخفی‌سازی CSS نیست.
