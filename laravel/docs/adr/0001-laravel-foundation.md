# ADR 0001: ساخت پایهٔ Laravel کنار سامانهٔ قدیمی

- وضعیت: پذیرفته‌شده برای توسعهٔ پایه؛ تصمیم انتشار/جایگزینی تولید باز است.
- تاریخ: ۲۰۲۶-۱۰-۰۵

## زمینه

ریشهٔ repository برنامهٔ PHP قدیمی پرماپی است و باید در دورهٔ ساخت حفظ شود. محیط توسعه PHP 8.2.12 دارد؛ Laravel 13 به PHP 8.3 نیاز دارد. قوانین پرداخت، تخصیص قسط و جریمه در Legacy وجود دارند و هنوز به مدل مقصد منتقل یا به‌طور کامل آزموده نشده‌اند.

## تصمیم

برنامهٔ جدید در `laravel/` مستقل ساخته می‌شود. برای سازگاری با PHP توسعهٔ فعلی Laravel 12 انتخاب شده است. UI برای فارسی و RTL طراحی می‌شود. مبالغ در واحد تومان صحیح ذخیره می‌شوند. UI/API عملیات مالی را تا زمانی که رفتار و مرجع محاسباتی تطبیق داده نشده، تسویه‌شده جلوه نمی‌دهند.

## پیامدها

- Legacy می‌تواند برای استخراج و اجرای موازی در دسترس بماند.
- تغییرات این برش در commit جداگانه زیر مسیر `laravel/` ثبت می‌شوند.
- Laravel 12 و PHP 8.2 یک سکوی انتقالی‌اند؛ برای افق پشتیبانی بهتر ارتقا به PHP 8.3/Laravel 13 باید برنامه‌ریزی و جداگانه بازاعتبارسنجی شود.
- SQLite صرفاً برای توسعه و اجرای محلی تأیید شده؛ قفل و تراکنش مالی باید روی نسخهٔ واقعی MySQL/MariaDB اثبات شوند.
- این ADR مجوز خاموش‌کردن یا مهاجرت دادهٔ production نیست.

## گزینه‌های باز

محل استقرار، نسخهٔ MySQL/MariaDB، صف/کش production، روش انتقال هر حوزه، gateway، نگهداری افزونه‌های Legacy و سیاست cutover هنوز تصمیم نهایی ندارند.
