# گزارش تحویل این برش

## انجام‌شده

- برنامهٔ Laravel مستقل در `laravel/`، با حفظ مسیرهای Legacy در ریشه.
- رابط ورود، داشبورد، فهرست/ساخت/جزئیات مشتری، KYC، اعتبار و درخواست پرداخت با متن فارسی، جهت RTL و چیدمان واکنش‌گرا.
- پایهٔ auth/RBAC/شعبه، API Sanctum، KYC، دفترکل تغییر سقف، payment intent معلق، schema پایهٔ مشتری/قرارداد/قسط، مبلغ صحیح تومان و حفاظت دادهٔ کد ملی.
- مستندات معماری، نقشهٔ قابلیت، نگاشت همهٔ ۷۲ جدول Legacy، پایگاه داده، API، امنیت، اجرا، استقرار و برنامهٔ انتقال.

## محدودیت صریح

این تحویل مهاجرت کامل پروژه یا محصول آمادهٔ production نیست. داده منتقل نشده؛ ایجاد و چرخهٔ قرارداد/قسط، تخصیص و تسویهٔ پرداخت، درگاه و webhook، قوانین جریمه/بخشش، import، اسناد، WordPress/WooCommerce و observability کامل باقی مانده‌اند. schema/app فقط روی SQLite محلی بازبینی شده؛ MySQL واقعی و قواعد مالی Legacy تطبیق نشده‌اند. پیش از استفاده برای حساب واقعی این کارها و بازبینی امنیت لازم‌اند.

## کنترل‌های اجراشده در برش اولیه

`migrate:fresh --seed` روی SQLite موفق شد؛ `php artisan test --compact` با ۱۳ تست/۶۳ assertion، `npm run build`، `composer validate --no-check-publish`، `composer audit` بدون advisory، `vendor/bin/pint --test` پس از قالب‌بندی و PHP syntax check (۶۷ فایل) موفق شدند. UI روی desktop و mobile بازبینی چشمی شد.

## شواهد افزوده‌شده در ادامهٔ کار

در ۲۰۲۶-۱۰-۰۵، migration و seed و همان ۱۳ تست/۶۳ assertion روی MariaDB 10.4.32 در یک datadir آزمایشی جدا و فقط روی loopback هم موفق شدند. این نتیجه نسخهٔ production را تأیید نمی‌کند و تست هم‌زمانی یا گردش مالی کامل نیست؛ جزئیات در [MYSQL-TESTING.md](MYSQL-TESTING.md) آمده است.

در ادامه، محاسبهٔ قیمت/قسط Legacy به کلاس مستقل `Domain\Contracts\ContractPricingCalculator` منتقل شد و برای رفتار ساده/مرکب، گردکردن، رقم فارسی، پایان ماه و ورودی نامعتبر تست واحد اضافه شد. سپس مسیر پیش‌نویس قرارداد با شماره‌گذاری قفل‌شده، idempotency، آخرین KYC تأییدشده، snapshot محاسبه، ثبت اقساط در batch و audit ساخته شد. فرم فارسی/RTL در صفحهٔ پرونده و API v1 اضافه شد. آزمون‌ها تعارض idempotency، دسترسی شعبه/نقش، و ممنوعیت پیش‌پرداخت بیشتر از اصل را پوشش می‌دهند. اکنون ۳۳ تست/۱۳۹ assertion روی SQLite و MariaDB موفق است. پیش‌نویس اعتبار رزرو نمی‌کند و پولی ثبت نمی‌کند؛ approval/activation/payment/allocation هنوز وجود ندارد و این گزارش تأیید آمادگی production نیست.

## گیت

تنها مسیر `laravel/` برای این برش stage و commit می‌شود؛ فایل‌های قدیمی/تغییرکردهٔ خارج از آن جزو این commit نیستند.
