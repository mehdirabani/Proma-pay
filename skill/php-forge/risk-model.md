# Risk Model — v1.2

R0 informational; R1 low-risk/text/UI; R2 ordinary code change; R3 elevated state/data/external input; R4 high-risk security/payment/migration; R5 critical financial/auth/authz/encryption/destructive production operations.

Risk is derived from concepts + scope + repository evidence rather than isolated domain words. High-risk Security/FinTech defaults to supervised autonomy.
