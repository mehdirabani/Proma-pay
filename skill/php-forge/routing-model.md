# Routing Model — Semantic Router V3

Layer A: deterministic high-risk concept evidence from the registry.

Layer B: local latent-semantic fallback (word/character TF-IDF + TruncatedSVD + cosine similarity) only when deterministic concept evidence is absent. This is semantic vector matching, not a foundation-model understanding claim.

Layer C: repository/package evidence, dependency resolution, scope/negation suppression, risk and context budgeting.

Confidence labels are heuristic and not probability-calibrated.
