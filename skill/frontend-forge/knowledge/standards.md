# Current Standards Notes

- Accessibility target: WCAG 2.2 AA for applicable production interfaces.
  Source: https://www.w3.org/WAI/standards-guidelines/wcag/
- Tailwind responsive utilities are mobile-first; v4 includes container queries in core.
  Source: https://tailwindcss.com/docs/responsive-design
- Next.js documentation distinguishes App Router and Pages Router; App Router supports React Server Components.
  Source: https://nextjs.org/docs

Profiles must be checked against the project's installed versions before applying version-specific advice.
