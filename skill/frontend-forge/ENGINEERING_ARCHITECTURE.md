# V15.1 Engineering Architecture

## Evidence Before Autonomy
Observation is not evidence. User symptom text remains a symptom signal until repository/tool observation
produces typed evidence bound to workspace, revision, task and target.

## Trust chain
Task → observed repository state → typed evidence → decision → durable change → validation evidence.

## Maturity
Capabilities are labeled STUB, IMPLEMENTED, VERIFIED_UNIT, VERIFIED_FIXTURE,
VERIFIED_E2E_FIXTURE, VERIFIED_REAL_PROJECT, or PRODUCTION_READY.
