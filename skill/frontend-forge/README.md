# Frontend Forge X v15.3
## Observation-Authenticated Evidence, Policy-Enforced Autonomy & Causal Patch Generation

V15.3 closes trust gaps between signed claims and real observations.
Production invariants:
- callers request observations; they do not supply trusted observation payloads
- registered collectors execute against current repository/tool state
- central signing authority enforces broker record-type ACLs
- plan/autonomy/root-cause gates authorize every production patch
- repair patches must be causally bound to a verified mechanism
- change receipts are cryptographically verified by evaluators
- blind benchmark execution is separated from sealed evaluation data
