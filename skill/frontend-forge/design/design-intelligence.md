# Design Intelligence

Analyze:
visual hierarchy, spacing, typography, density, readability, responsive behavior,
interaction states, conversion goals, accessibility, consistency, design tokens.

Responsive rule:
prefer content-driven breakpoints and container queries when component behavior
depends on available container space; viewport breakpoints remain appropriate for
page-level layout changes.

Animations:
prefer transform/opacity; respect reduced motion; avoid layout-triggering motion when possible.
