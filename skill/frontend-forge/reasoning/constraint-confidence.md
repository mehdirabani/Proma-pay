# Constraint & Confidence Engine

Constraint classes:
- hard: cannot be violated
- soft: optimize when possible
- preference: lowest priority

Confidence:
0.80–1.00 high
0.60–0.79 moderate
<0.60 low

Low confidence triggers one of:
- more context
- second-agent review
- simulation
- explicit uncertainty in output

Confidence is not a quality score; it expresses evidence sufficiency for a decision.
