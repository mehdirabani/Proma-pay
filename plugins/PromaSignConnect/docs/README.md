# Proma Sign & Connect

افزونه مستقل ارتباطات چندکاناله و تأیید/امضای الکترونیکی داخلی. نسخهٔ جاری افزونه `1.2.3` کاندید Core `2.2.11` است؛ `tested_core_max` در manifest هنوز `1.5.5` است، پس سازگاری با Coreهای جدیدتر تأیید نشده.

ورود مشتری با OTP در این نسخه پشتیبانی نمی‌شود و هیچ route یا تنظیمی برای آن ثبت نشده است. OTP برای امضا و تأیید عملیات حساس باقی است. تاریخچه امضا و ارسال در uninstall عادی حفظ می‌شود.
