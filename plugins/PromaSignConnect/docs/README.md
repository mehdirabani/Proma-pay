# Proma Sign & Connect

افزونه مستقل ارتباطات چندکاناله و «تأیید و امضای الکترونیکی داخلی» برای Proma Pay Core 1.5.1 و Plugin API 1.0.

ورود با چهار رقم آخر موبایل حذف یا جایگزین نشده است. OTP تنها یک روش اختیاری موازی و ابزار تأیید عملیات حساس است. تاریخچه امضا و ارسال در uninstall عادی حفظ می‌شود.
