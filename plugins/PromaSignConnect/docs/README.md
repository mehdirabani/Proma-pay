# Proma Sign & Connect

افزونه مستقل ارتباطات چندکاناله و تأیید/امضای الکترونیکی داخلی، نسخهٔ `1.3.1`. حداقل Core مورد نیاز `6.0.2` است و manifest حداکثر نسخهٔ Core ثبت‌شده را `7.0.3` اعلام می‌کند. ساخت بسته به‌تنهایی به معنی تأیید ارسال زنده از ارائه‌دهندگان خارجی نیست.

ورود مشتری با OTP در این نسخه پشتیبانی نمی‌شود و هیچ route یا تنظیمی برای آن ثبت نشده است. OTP برای امضا و تأیید عملیات حساس باقی است. تاریخچه امضا و ارسال در uninstall عادی حفظ می‌شود.
