# مرکز تنظیمات حرفه‌ای

مرکز تنظیمات دارای ۱۵ بخش مستقل است: نمای کلی، پیامک، بله، تلگرام، OTP، امضا، ماتریس اعلان، قالب‌ها، routing، webhook، امنیت، گزارش تحویل، سلامت، عیب‌یابی و نگهداری.

هر ارائه‌دهنده و قابلیت مستقل است. غیرفعال‌سازی باعث حذف secret، سابقه، قالب یا اتصال کاربر نمی‌شود. تست اتصال خودکار هنگام بازشدن صفحه انجام نمی‌شود.
