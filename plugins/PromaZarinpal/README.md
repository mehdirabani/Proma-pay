# درگاه پرداخت زرین‌پال پرما

افزونه رسمی اتصال Proma Pay به API نسخه ۴ زرین‌پال، با پشتیبانی از پرداخت تک‌قسطی، پرداخت چندقسطی، محیط عملیاتی و آزمایشی، Verify سمت سرور و callback مستقل از session.

## نیازمندی‌ها

- Proma Pay `>= 1.2.6` (پیشنهاد: `1.3.4` یا جدیدتر)
- PHP `>= 8.1`
- افزونه‌های PHP: `pdo_mysql`, `curl`, `openssl`, `json`, `mbstring`
- HTTPS معتبر برای Callback عملیاتی

## نصب

1. فایل `PromaZarinpal-1.0.0.zip` را از «پلاگین‌ها» بارگذاری کنید.
2. افزونه `proma-zarinpal` را نصب و سپس فعال کنید.
3. از زیرمنوی «درگاه زرین‌پال ← تنظیمات درگاه» Merchant محیط موردنظر را ثبت کنید.
4. درگاه پس از نصب به صورت پیش‌فرض غیرفعال است.

## قواعد مالی

- مبلغ داخلی سامانه تومان است.
- در حالت `IRT` همان مبلغ و در حالت `IRR` مبلغ ضربدر ۱۰ ارسال می‌شود.
- Verify همیشه با مبلغ، محیط و Merchant snapshot ذخیره‌شده زمان initiation انجام می‌شود.
- callback تکراری و کد `101` تخصیص مالی دوباره ایجاد نمی‌کنند.
- افزونه جریمه، پاداش، مانده و ترتیب تخصیص را محاسبه نمی‌کند؛ این موارد در هسته Proma Pay باقی می‌مانند.

## داده محرمانه

Merchant ID با AES-256-GCM رمز می‌شود. کلید در `storage/private/proma-zarinpal.key` و خارج از دیتابیس قرار می‌گیرد. این فایل باید در بکاپ امن سرور نگه‌داری شود و نباید در بسته بروزرسانی جایگزین گردد.

مستندات کامل در `docs/plugins/PROMA_ZARINPAL.md` قرار دارد.
