# تغییرات افزونه زرین‌پال

## 1.0.7 — 2026-10-18 (Proma Pay V7.0.3 Candidate)

- فرادادهٔ انتشار افزونه با Core V7.0.3 همگام شد؛ Plugin API 1.1 و حداقل Core پشتیبانی‌شده حفظ شده‌اند.

## 1.0.6 — 2026-10-13 (Proma Pay V7.0.0 Candidate)

- نسخهٔ افزونه برای بستهٔ سازگار V7 منتشر شد؛ حداقل Core و Plugin API برای ارتقای نصب‌های موجود حفظ شده‌اند.
- این بستهٔ Candidate است و تبادل واقعی با درگاه در محیط تولید V7 تأیید نشده است.

## 1.0.5 - 2026-10-12 (Proma Pay V6.0.2)

- manifest با Plugin API 1.1 و حداقل نسخهٔ هستهٔ V6.0.2 همگام شد.
- بستهٔ افزونه برای نصب و چرخهٔ به‌روزرسانی هستهٔ جاری بازبسته‌بندی شد.

## 1.0.4 - 2026-10-08 (V5 Candidate)

- بستهٔ نصب برای Proma Pay V5؛ حداقل نسخهٔ هسته در manifest به `5.0.0` تغییر کرد.
- نسخهٔ PHP در محیط محلی 8.5.7 از نظر نحوی بررسی شد؛ نصب عملیاتی افزونه هنوز تأیید نشده است.

## 1.0.3 - 2026-10-05

- انتقال دامنه تسویه قرارداد و هزینه حقوقی به پرداخت گروهی زرین‌پال، برای پشتیبانی از پرداخت مستقل هزینه‌های حقوقی.

## 1.0.2 - 2026-10-04

- افزایش patch version برای انتشار همراه Proma Pay Core 2.2.0؛ تغییر API، schema یا رفتار در این bump انجام نشد.

## 1.0.1 - 2026-07-19

- کنترل‌های فرم افزونه با توکن‌های مشترک Proma Pay همگام شد تا حالت filled، focus قابل مشاهده و چینش RTL در کنار هسته یکدست باشد.

## 1.0.0 - 2026-07-13

- اتصال رسمی Zarinpal Payment API v4 برای production و sandbox.
- پرداخت تک‌قسطی، جزئی و چندقسطی با تخصیص هسته.
- Verify با مبلغ ذخیره‌شده و پشتیبانی idempotent از codeهای 100 و 101.
- تنظیمات رمزگذاری‌شده و Merchantهای جداگانه هر محیط.
- پنل تراکنش، فیلتر، خروجی CSV و بررسی مجدد کنترل‌شده.
- callback عمومی بدون session، محدود به Authority و Status.
- جلوگیری از غیرفعال‌سازی افزونه در زمان وجود تراکنش unresolved.
