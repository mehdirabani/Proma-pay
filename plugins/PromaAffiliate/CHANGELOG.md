# PromaAffiliate Changelog

## 1.1.1 — 2026-10-18 (Proma Pay V7.0.3 Candidate)

- فرادادهٔ انتشار افزونه با Core V7.0.3 همگام شد؛ Plugin API 1.1 و حداقل Core پشتیبانی‌شده حفظ شده‌اند.

## 1.1.0 — 2026-10-16 (Proma Pay V7.0.1 Candidate)

- نصب افیلیت دیگر به فعال‌بودن قبلی Accounting وابسته نیست؛ Health Check نصب تازه و بدون تراکنش را سالم می‌پذیرد.
- عملیات اعتبار و پاداش تا فعال‌شدن Accounting همچنان متوقف می‌مانند تا هیچ تغییر مالی بدون ثبت دفترکل انجام نشود.

## 1.0.9 — 2026-10-13 (Proma Pay V7.0.0 Candidate)

- اجرای فرمان‌های SQL-level `PREPARE`، `EXECUTE` و `DEALLOCATE PREPARE` در مهاجرت‌ها با `PDO::exec` اصلاح شد؛ نصب افلیت در migration کیف پول متوقف نمی‌شود و اجرای دوباره ستون‌های موجود را حفظ می‌کند.
- نسخهٔ هستهٔ همراه، اجرای این فرمان‌ها را در runner مهاجرت افزونه‌ها پشتیبانی می‌کند.

## 1.0.8 — 2026-10-13 (Proma Pay V7.0.0 Candidate)

- نسخهٔ افزونه برای بستهٔ سازگار V7 منتشر شد؛ وابستگی به PromaAccounting و حداقل نسخهٔ Core برای حفظ نصب‌های موجود نگه داشته شده است.
- این بستهٔ Candidate است و گردش معرف، اعتبار خرید و برداشت در محیط عملیاتی V7 تأیید نشده است.

## 1.0.7 — 2026-10-12 (Proma Pay V6.0.2)

- سازگاری manifest با Plugin API 1.1 و حداقل هستهٔ V6.0.2 همگام شد.
- وابستگی Accounting با نسخهٔ جاری افزونهٔ حسابداری در بستهٔ هماهنگ‌شده حفظ شد.

## 1.0.6 — 2026-10-08 (V5 Candidate)

- بستهٔ نصب برای Proma Pay V5؛ حداقل نسخهٔ هسته در manifest به `5.0.0` تغییر کرد.
- نسخهٔ PHP در محیط محلی 8.5.7 از نظر نحوی بررسی شد؛ نصب عملیاتی افزونه هنوز تأیید نشده است.

## 1.0.5 — 2026-10-06

- آمار پاداش معرفان را با عدد صحیح تومان جمع می‌زند.
- شکست ثبت هم‌زمان دفترکل اکنون تراکنش افیلیت را متوقف و rollback می‌کند تا خطای مالی پنهان نماند.
- Triggerهای customer-created، sale-created و first-purchase از هم تفکیک شدند؛ ثبت فروش پس از انتخاب معرف قراردادی و کد معرف ثبت‌نامی پوشش داده می‌شود.
- Accounting به وابستگی فعال تبدیل شد و Health Check اختلاف wallet/ledger را از روی کلید idempotency گزارش می‌کند.

## 1.0.4 — 2026-10-05

- ثبت کمیسیون مستقل برای هر قرارداد از معرف افیلیت انتخاب‌شده؛ کمیسیون پس از اولین پرداخت موفق قرارداد یا بلافاصله پس از ثبت قرارداد محاسبه می‌شود.
- نمایش فروش‌های منتسب در پنل کسب درآمد مشتری و مدیریت.
- حفظ اطلاعات برداشت، گردش موجودی، حداقل مبلغ و تأیید مرحله‌ای نسخهٔ قبل.

## 1.0.3 — 2026-10-05

- افزوده‌شدن اطلاعات کارت و حساب ذخیره‌شده برای برداشت مشتری.
- افزوده‌شدن حداقل مبلغ برداشت قابل تنظیم، تأیید مرحله‌ای برداشت و فهرست/اصلاح ممیزی‌پذیر موجودی معرفان.
- افزودن جستجوی معرف افیلیت در ثبت قرارداد و نمایش بخش مشتری با عنوان «کسب درآمد».

## 1.0.2 — 2026-10-04

- Patch version bump for the Proma Pay Core 2.2.0 candidate release. Plugin API, database schema, and runtime behavior are unchanged by this version bump.
