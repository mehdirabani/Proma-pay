# Changelog

## 2.0.0-alpha.2 — 2026-10-22

- اتصال ورودی‌های تاریخ خرید، شروع شراکت، هزینه و بازهٔ گزارش به انتخابگر شمسی مشترک.
- نمایش انتخابگر مشترک روی دیالوگ‌های بومی سیستم و بازگرداندن آن پس از بستن.

## 2.0.0-alpha.1 — 2026-10-21

- ایجاد provider و permission namespace مستقل برای successor.
- ادامهٔ جداول دادهٔ عملیاتی `plugin_inventory_*` بدون کپی کالا، فروش یا journal.
- افزودن گارد lifecycle برای جلوگیری از فعال‌بودن هم‌زمان افزونهٔ قدیمی و successor.
- افزودن نسخه‌بندی سیاست مالی، ثبت hash و صفحهٔ تنظیم/پیش‌نمایش اقساط.
- افزودن محاسبهٔ integer-Rial برای سود ساده/مرکب، دو مبنای تأمین مالی و توزیع ماندهٔ اقساط.
- حفظ مسیرهای موجود برای bookmarkها و مستندکردن نگاشت permissionها و محدودیت‌های migration.
