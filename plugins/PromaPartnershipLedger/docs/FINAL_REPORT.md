# گزارش نهایی این نوبت

تاریخ: ۲۰۲۶-۱۰-۲۲
نسخه: `PromaPartnershipLedger 2.0.0-alpha.1`
وضعیت محصول: build آزمایشی؛ Production readiness تأیید نشده است.

## انجام‌شده

- successor یکپارچه با provider، namespace، شناسه و permissionهای مستقل ساخته شد.
- موجودی، فروش و دفترکل از همان جداول `plugin_inventory_*` استفاده می‌کنند؛ دفتر موازی ساخته نمی‌شود. migration اختصاصی نسخه‌های قواعد مالی را اضافه می‌کند.
- guard فعال‌سازی متقابل در هر دو provider وجود دارد.
- موتور محاسبهٔ اقساط ریالی و ثبت نسخهٔ تغییرناپذیر سیاست مالی با SHA-256 پیاده‌سازی شد.
- گزارش parity، migration، cutover، rollback و راهنمای نصب همراه بسته هستند.
- آزمون PHP/JavaScript/domain/manifest/MySQL موفق بود؛ جزئیات آزمون‌های مرورگر و preview در `TEST_REPORT.md` آمده است.

## نتیجهٔ آزمون محلی

- در اولین مشاهدهٔ این نوبت، `proma-partnership-ledger` از قبل فعال و `proma-inventory-partners` در رجیستری `removed` بود؛ پوشهٔ legacy در runtime وجود نداشت. این نوبت lifecycle هیچ‌کدام را تغییر نداد.
- هر سه migration successor موفق ثبت شده‌اند. ۱۶ صفحهٔ مدیریتی باز شدند؛ preview ساده و مرکب محاسبه شد و هیچ سند یا نسخهٔ سیاستی ذخیره نشد.
- دیتابیس `proma_test` یک انبار و صفر ردیف عملیاتی موجودی/شراکت داشت. جداول عملیاتی پس از آزمون نیز بدون تغییر ماندند.

## شکاف‌های باقی‌مانده

- parity روی دادهٔ عملیاتی غیرخالی، rollback واقعی و گردش کامل خرید/فروش/پرداخت/تسویه روی staging آزموده نشده‌اند.
- قرارداد اقساطی هنوز با مبلغ قرارداد core یکپارچه نیست و snapshot فروش ندارد.
- مشارکت چندگانه، خرید و فروش چندردیفی، مرجوعی جزئی، شمارش انبار، بدهی تأمین‌کننده، بازسرمایه‌گذاری سود، بستن ماه و تسویهٔ نهایی کامل نیستند.
- اتصال‌های Accounting/Repair/Affiliate و hook اصلاح پرداخت نیاز به آزمون یکپارچه دارند.
- permissionهای role به شناسهٔ جدید خودکار نگاشت نشده‌اند.
- به‌دلیل نبود فایل legacy در runtime فعلی، rollback با یک کلیک ممکن نیست؛ ابتدا باید بستهٔ legacy بازگردانده و rollback روی staging آزموده شود.

## تصمیم

وضعیت فعلی runtime محلی با یک provider فعال است؛ بااین‌حال این build فقط برای آزمون/staging است و برای Production تأیید نمی‌شود. پیش از تغییر lifecycle، از برنامهٔ cutover/rollback و گزارش به‌روز migration استفاده کنید.
