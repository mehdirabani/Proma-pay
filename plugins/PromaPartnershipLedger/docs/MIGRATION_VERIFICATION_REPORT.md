# گزارش تطبیق Migration

تاریخ: ۲۰۲۶-۱۰-۲۱. وضعیت: ممیزی کد انجام شد؛ دیتابیس زنده/staging در دسترس این بررسی نبود.

| شاخص | قبل | بعد | نتیجه |
|---|---|---|---|
| تعداد کالا، محموله و موجودی | نیازمند query از snapshot | successor هنوز روی DB نصب نشده | نامعلوم |
| بهای تمام‌شده | نیازمند query از snapshot | successor هنوز روی DB نصب نشده | نامعلوم |
| IMEI/Serial و وضعیت | نیازمند query از snapshot | successor هنوز روی DB نصب نشده | نامعلوم |
| گردش خرید/فروش/مرجوعی | نیازمند query از snapshot | successor هنوز روی DB نصب نشده | نامعلوم |
| سهم سرمایه و ماندهٔ شرکا | نیازمند query از snapshot | successor هنوز روی DB نصب نشده | نامعلوم |
| journal و تسویه | نیازمند query از snapshot | successor هنوز روی DB نصب نشده | نامعلوم |

در سطح سورس، عملیات zero-copy روی جداول `plugin_inventory_*` طراحی شده و migration افزونهٔ جدید دفترکل/موجودی موازی ایجاد نمی‌کند. این به تنهایی تطبیق دادهٔ واقعی را ثابت نمی‌کند.

هیچ cutover، غیرفعال‌سازی یا حذف افزونهٔ قدیمی انجام نشده است. مراحل و شروط تکمیل در `MIGRATION_PLAN.md`, `CUTOVER_PLAN.md` و `ROLLBACK_PLAN.md` هستند.
