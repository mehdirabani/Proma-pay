## تصمیم اجرایی پیش از cutover

این گزارش پیش از هرگونه غیرفعال‌سازی افزونهٔ قدیمی ارائه می‌شود. snapshot محلی نشان می‌دهد در حال حاضر دادهٔ عملیاتی موجودی/شراکت برای مهاجرت نداریم، اما parity کامل محصول و آزمون جریان‌های مالی/مجوزها هنوز تأیید نشده است. بنابراین این build برای آزمون محلی/staging است و cutover را مجاز نمی‌کند. افزونهٔ قدیمی فعال می‌ماند؛ uninstall، purge و حذف داده انجام نمی‌شود. افزونهٔ جدید را می‌توان نصب کرد و guard فعال‌سازی متقابل را بدون تغییر نویسندهٔ داده آزمود.

## شواهد و محدودیت‌ها

- queryهای شمارش و جمع فقط‌خواندنی روی `proma_test` اجرا شدند؛ queryها هیچ تغییری در داده‌ها ندادند.
- migration افزایشی قبلاً با موفقیت دو بار اجرا شده و جدول سیاست دقیقاً یک‌بار وجود دارد.
- آزمون تراکنشی سرویس سیاست مالی، hash، audit و rollback موفق بود و دادهٔ QA باقی نگذاشت.
- هنوز جابه‌جایی provider، آزمون parity روی دادهٔ عملیاتی غیرخالی، آزمون کامل UI و آزمون rollback cutover اجرا نشده‌اند.
