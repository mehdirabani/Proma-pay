# نقشهٔ یکپارچگی

| سامانه | مرجع داده/منطق | وضعیت successor |
|---|---|---|
| Proma Pay Core | قرارداد، اقساط، پرداخت، کاربران و Plugin Manager | hookهای `payment.completed` و `contract.cancelled` حفظ شده‌اند؛ hook عمومی اصلاح پرداخت در ممیزی فعلی پیدا نشد |
| PromaAccounting | کمیسیون فروشنده و حساب‌های کاربران | اتصال و تطبیق جلوگیری از دوباره‌شماری هنوز پیاده/آزموده نشده است |
| PromaRepair | پرونده تعمیر و خدمات | اتصال درآمد/هزینهٔ مشارکت هنوز پیاده/آزموده نشده است |
| PromaAffiliate | معرفی مشتری و پاداش | adapter و جلوگیری از دوباره‌شماری هنوز پیاده/آزموده نشده است |
| PromaZarinpal | تراکنش درگاه | اتصال از جریان core باقی می‌ماند؛ آزمون end-to-end successor انجام نشده است |
| PromaSignConnect | اعلان و امضای سند | اتصال اختیاری هنوز پیاده نشده است |

افزونه‌های اختیاری نباید مسیرهای مستقل successor را از کار بیندازند. هر اتصال باید مرجع رویداد یکتا، idempotency و آزمون تکرار داشته باشد.
