# Changelog

## 1.2.28 — 2026-10-18 (Proma Pay V7.0.3 Candidate)

- فرادادهٔ انتشار افزونه با Core V7.0.3 همگام شد؛ Plugin API 1.1 و حداقل Core پشتیبانی‌شده حفظ شده‌اند.

## 1.2.27 — 2026-10-13 (Proma Pay V7.0.0 Candidate)

- نسخهٔ افزونه برای بستهٔ سازگار V7 منتشر شد؛ حداقل Core و Plugin API برای ارتقای نصب‌های موجود حفظ شده‌اند.
- این بستهٔ Candidate است؛ گردش‌های مالی افزونه روی دیتابیس عملیاتی بررسی نشده‌اند.

## 1.2.26 — 2026-10-12 (Proma Pay V6.0.2)

- سازگاری manifest با Plugin API 1.1 و حداقل هستهٔ V6.0.2 همگام شد.
- بستهٔ افزونه با هستهٔ V6.0.2 و گردش‌های مالی جدید هم‌نسخه شد.

## 1.2.25 — 2026-10-08 (V5 Candidate)

- بستهٔ نصب برای Proma Pay V5؛ حداقل نسخهٔ هسته در manifest به `5.0.0` تغییر کرد.
- نسخهٔ PHP در محیط محلی 8.5.7 از نظر نحوی بررسی شد؛ نصب عملیاتی افزونه هنوز تأیید نشده است.

## 1.2.24 — 2026-10-06

- حساب‌ها و گردش‌های مالی مشتریان در فهرست‌ها و جمع‌های حسابداری داخلی نمایش داده نمی‌شوند؛ گزارش‌های افیلیت همچنان مرجع پاداش و گردش بازاریابی مشتری هستند.

## 1.2.23

- پاک‌سازی routeهای بلااستفادهٔ Salary و Referral/Withdrawal از manifest طبق حذف رابط کاربری در نسخهٔ ۱.۲.۱۴؛ migrationها و سابقهٔ مالی حفظ شدند.
- حذف permissionهای یتیم و تکراری؛ آزمون سراسری صحت manifestها به گیت انتشار افزوده شد.

## 1.2.22

- انتساب فروشنده و بازاریاب به نقش‌های فعال داخلی شامل مدیر، اپراتور، وکیل و تعمیرکار محدود شد؛ مشتری عادی نمی‌تواند دریافت‌کنندهٔ قانون کمیسیون باشد.
- حساب مشتریان برای ثبت گردش مالی مشتری‌محور در دسترس نقش‌های مجاز حسابداری باقی می‌ماند.

## 1.2.20

- افزایش patch version برای انتشار همراه Proma Pay Core 2.2.0؛ تغییر API، schema یا رفتار افزونه در این bump انجام نشد.

## 1.2.7

- داشبورد مالی شخصی و تحلیل مالی کاربران با scope مجوزدار اضافه شد.
- عنوان گزارش به «گزارش درآمد، هزینه و خالص عملکرد مالی» محدود شد؛ این گزارش سود و زیان رسمی شرکت نیست.
- طبقه‌بندی درآمد/هزینه/خنثی و migrationهای analytics اضافه شد.
- قوانین حقوق ثابت و ثبت دورهٔ idempotent با تفکیک ثبت حقوق از پرداخت حقوق اضافه شد.
- MoneyInput برای جداسازی سه‌رقمی و پشتیبانی از ارقام فارسی/عربی/انگلیسی اضافه شد؛ اعتبارسنجی سمت سرور همچنان مرجع است.
- endpoint تجمیعی analytics بدون polling و با بازهٔ تاریخ محدود اضافه شد.

## 1.2.0

- بازطراحی یکپارچه تمام صفحات افزونه با توکن‌های رسمی Proma Pay و CSS کاملاً scoped.
- داشبورد شش KPI، نمودار محلی Chart.js، عملیات سریع و آخرین تراکنش‌ها اضافه شد.
- جدول‌های دسکتاپ و کارت‌های موبایل برای حساب‌ها، فروش، دفترکل و کمیسیون‌ها بازطراحی شدند.
- فرم‌های ۴۴ پیکسلی، ورودی مبلغ محلی، switchها، وضعیت‌های خالی و مودال تأیید مالی استاندارد شدند.
- حالت تاریک، focus قابل مشاهده، reduced motion، دکمه loading و جلوگیری از ارسال تکراری تکمیل شد.
- دارایی‌های افزونه فقط روی routeهای حسابداری بارگذاری می‌شوند؛ هیچ migration یا محاسبه مالی تغییر نکرد.

## 1.1.0

- بازطراحی کامل RTL تمام صفحات حسابداری با padding و فرم مشترک
- برچسب‌ها، واحدها، راهنماها، switchها و validationهای روشن
- `CommissionCalculationService` مشترک برای preview و فروش واقعی
- پشتیبانی از مبلغ کل، تأمین مالی‌شده، سود و مبلغ وصول‌شده
- کف، سقف و چهار روش گردکردن با محاسبات integer
- wizard ده‌مرحله‌ای با ذخیره پیشرفت و امکان ردکردن موقت
- مرکز راهنمای داخلی و قواعد شفاف مانده
- جریان کامل تأیید، ثبت idempotent و معکوس‌سازی کمیسیون
- migration سازگار بدون بازنویسی مانده، دفترکل و کمیسیون تاریخی
