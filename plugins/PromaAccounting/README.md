# Proma Accounting

افزونه‌ی مستقل حسابداری کاربران برای Proma Pay است. تا وقتی افزونه نصب و فعال نشده باشد، هسته‌ی قرارداد و پرداخت بدون وابستگی به جدول‌های این پوشه کار می‌کند.

## قواعد مالی

- `credit` موجودی حساب کاربر را افزایش می‌دهد.
- `debit` موجودی حساب کاربر را کاهش می‌دهد.
- سندهای دفترکل حذف یا ویرایش نمی‌شوند؛ اصلاح با سند معکوس انجام می‌شود.
- فروش هر قرارداد با `contract_id` یکتا ثبت می‌شود.
- کمیسیون بر اساس rule فعال و basis مشخص محاسبه می‌شود.

حداقل PHP این نسخه 8.1 است و نصب افزونه باید بعد از backup انجام شود.
