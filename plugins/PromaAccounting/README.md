# Proma Accounting 1.1.0

افزونه مستقل حسابداری کاربران برای Proma Pay است. نصب، بروزرسانی و حذف منطقی آن از هسته جداست و غیرفعال‌کردن افزونه، قراردادها و پرداخت‌های هسته را مختل نمی‌کند.

## نیازمندی‌ها

- Proma Pay `1.2.6` یا جدیدتر
- PHP `8.1` یا جدیدتر
- MySQL/MariaDB با پشتیبانی InnoDB و `utf8mb4`
- افزونه PHP Zip برای بارگذاری بسته

## راه‌اندازی

1. پیش از نصب یا بروزرسانی بکاپ کامل بگیرید.
2. فایل `PromaAccounting-v1.1.0.zip` را از مدیریت پلاگین‌ها بارگذاری کنید.
3. در نصب تازه، پلاگین را نصب و فعال کنید و wizard ده‌مرحله‌ای را انجام دهید.
4. در بروزرسانی از `1.0.0`، دکمه بروزرسانی را بزنید تا migration جدید اجرا شود.
5. از «تنظیمات حسابداری» preview محاسبه را بررسی کنید.

## ترتیب محاسبه کمیسیون

1. قانون اختصاصی فروشنده، سپس قانون عمومی و در نهایت تنظیمات پیش‌فرض
2. تعیین مبلغ مبنا
3. محاسبه مبلغ خام
4. اعمال حداقل
5. اعمال حداکثر
6. گرد کردن integer
7. ذخیره snapshot محاسبه
8. ثبت در دفترکل بر اساس زمان و تأیید تنظیم‌شده

## قواعد مانده

- کمیسیون، پاداش، هزینه قابل پرداخت و دریافت وجه از کاربر: افزایش مانده
- کسورات و پرداخت وجه به کاربر: کاهش مانده
- اصلاح سند: ثبت سند معکوس؛ سند تاریخی ویرایش یا حذف نمی‌شود

Preview هیچ رکوردی ذخیره نمی‌کند. تغییر تنظیمات، کمیسیون‌های تأییدشده، ثبت‌شده، پرداخت‌شده یا معکوس و همچنین مانده و دفترکل موجود را بازنویسی نمی‌کند.
